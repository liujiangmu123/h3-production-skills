# 接入与本机路径说明

导出的8项技能正文和参考与生产源逐字节一致。部分文件仍引用原工作站的 `G:/AI`、`D:/AI`、研究档案和本地测试记录。这些是来源/工程入口，不是随仓库一起交付的资源。

## 需要的外部组件

- H3-pi-agent 的 `h3_*` 工具及相应生产桥。
- 配置好的ComfyUI及H3工作流、模型与音频路线。
- 所选系列的风格和选题技能；本库不另起风格默认。
- 工作室本身的量产总指导、工程和样本经验，按需准备。

## 路径映射

| 原工作站角色 | 本仓库或使用方对应 |
|---|---|
| `视频分析/skill/<序号_用途_name>` | 本仓库 `skills/<name>` |
| `montage/h3-agent/skills/core/h3-director` | `skills/h3-director` |
| Pi技能安装根 | 使用方配置的skillsRepo，按metadata.kind安装 |
| 本地风格/选题库与分镜台 | 使用方现有库，未随本仓库上传 |
| `H3动画量产_AI总指导.md`等工作室文件 | 使用方真实产线合同，缺少时先查工具/配置，不能猜参数 |

H3-pi-agent现有管理流程为 `verify → pack → install → verify`，安装时选新打包的明确zip路径，原安装覆盖遵守工具确认参数。自动挂载核心导演后，新会话读取；其他模块按需取。

不要将全部技能无差别自动加载，也不要修改独立风格/选题来满足通用评分。新的三项交接是普通Markdown，不能传成未定义JSON键。A线的until不能跨旁白句，hold与motion_rule要匹配过程；B线镜头允许范围、段长和续接保护窗以实际workflow为准。

精确动作、文字、数量、跨段身份等任务必须按已接入的能力落实；仅阅读技能不等于这些能力已经安装或验证。
