# 证据台账 · 含义对齐 · 边界复核

借鉴 `gnipbao/minimax-h3-video-reverse-skill`（v0.4 候选）的思路：先把视频变成有证据的事实，再把确认过的理解编译成规则、节拍或提示词。本线用在 ① 量完之后、② 写报告之前，以及 ⑦ 交接之前。脚本抽帧只是取证，不等于看过、听过。

## 一、建立视频事实（证据台账）

每支片在 `分析素材\<ID>\证据台账.md` 记一份。先跑 `analyze_reference.py --evidence`，它在 `evidence\` 抽首帧、最后一帧、最后 1 秒、每个硬切 / 单帧跳变 / 快速动作峰前后 1 秒的 10 fps 条（每格 0.1 秒）。

五遍看法：
1. 全片看一遍（不跳），写一句话梗概。
2. 定真实切镜：脚本的硬切 + 0.10–0.30 跳变逐个看条图，分清硬切 / 整屏重构图 / 快速运镜 / 淡入淡出。
3. 时间线连续覆盖：镜头表从 0 到视觉终点无空洞，黑场、字卡也算一段。
4. 关键处加密：快速动作、接触、遮挡、变形、道具交接，用 10 fps 条看清阶段。
5. 倒查结尾与最后三分之一：最后一帧是什么状态，结尾有没有被漏掉。

记录格式（一行一条事实，五类分开写，不混在一句里）：

| ID | 时间 s | 镜头 | 类别 | 事实 | 状态 | 证据 |
|---|---|---|---|---|---|---|
| F012 | 3.2–3.6 | S03 | 动作 | 右爪碰球后收回 | 已见 | EV007 条图 |

- 类别：外观（谁、长什么样、变化前后分开记）/ 道具（在哪、谁拿着、被挡住还是没了）/ 动作（接近、接触、停留、撤回、二次发力各记一条）/ 镜头（固定、推拉摇移、硬切；先看背景关系再判运镜）/ 声音（只记真听过的）。
- 状态三档：**已见**（运动至少要连续条图或两个不同时刻的帧）/ **待定**（看不清、推断）/ **用户设定**（用户说的，画面证明不了，原话照抄）。待定不进 skill 规则和提示词。
- 单张截图不能推断整段动作、速度和因果。
- 结尾状态写四档之一：已落定 / 仍在进行 / 被剪断 / 不清楚。不替原片补结局。
- 声音状态：已逐段听过 / 只看了波形或 ASR / 没听。ASR 文本要逐字听校才算"已听"。

## 二、对齐视频含义（含义层）

动作序列写对，不等于理解对了。例：猫随音乐举爪、扭身，最后突然停住看镜头——动作全记对，但笑点在"一本正经跳了半天，最后发现被拍"的落差；漏了这一层，写出来的只是"一只会动的猫"。

台账写完后，用 150–300 字中文复述，分成两栏：

- **看得见的**：谁在做什么 → 期待什么 → 转折（时间点）→ 反应 → 最后状态。缺哪一环直接说缺。
- **我的理解（待确认）**：笑点 / 落差 / 情绪 / 作者想让观众感到什么。非叙事片（演示、艺术、舞蹈）改问：展示目的 → 视觉过程 → 观看效果 → 终态。

然后只问一次，最多附 1–2 个关键歧义，等用户回复。规则：
- 用户没回、默认选项、"要准确" 都不算确认。用户纠正后回查受影响片段、重写复述。
- 用户"纠正 + 就按这个写"算确认，不再多问。
- 用户补的设定写进台账末尾「用户设定」节，和画面事实分开存，标"按你的说明理解"。确认故事不会让没听过的声音变成已听。
- 用户说"不用确认"时照做，但待定项仍标着。
- 含义层结论进 04 报告的爆点机制章（揭示时刻、落差、记忆点），不混进风格本质。

## 三、同一组事实，生成不同路线

所有下游写法都从台账投影，不另看一遍、不各自补细节：
- **文生视频时间线**：按真实时间线写全程，从第一镜写到最后状态。
- **图生视频**：首帧只写那一刻的静态状态（外观、道具位置、构图）；后续动作从这个状态出发，结束在台账记录的真实结尾状态。
- **多段衔接**：段界落在动作中间时，下一段开头必须继承上一段末尾的姿势、道具持握和未完成的动作；每段写清对应源时间。
- 改编（压时长、合镜头、加元素）要写明"有意偏离"清单，源事实不改。
- 本线的对应关系：主配方、节拍盲测、风格 skill 的样例段，都引用台账 ID。

## 四、边界复核清单（② 交报告前、⑦ 交接前各过一遍）

- [ ] 结尾：最后一帧和最后 1 秒看过了；结尾状态写了四档之一，没有补结局。
- [ ] 接触与撤回：多次触碰没被合并成一次；"之后"只用在前一动作确实结束时。
- [ ] 遮挡：被挡住的道具没被写成消失。
- [ ] 切镜与运镜：硬切没写成运镜，连续运镜没写成切镜，淡出没写成天黑。
- [ ] 声音：写进规则的声音都真听过；没听的标"未核听"，不编台词和配乐。
- [ ] 含义：复述用户确认过（或明说免确认）；用户设定没混进画面事实。
- [ ] 路线一致：各条路线覆盖同一段完整时间，首尾状态一致。
- [ ] 事实变了旧复核就失效：换了片、改了切点或关键动作、改了结尾，受影响的复述、报告结论、样例段要重新核，不能沿用旧勾选。
