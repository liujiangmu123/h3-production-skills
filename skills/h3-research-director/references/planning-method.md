# 通用找方向 / 选题方法（任何风格都按这个走）

来源：`shenhai-series-planner` v1.2（深海线 70 领域 + 25 叙事方向的实战）去掉深海专有部分后的通用骨架。**深海线以 `shenhai-series-planner` 为准**；新风格按本文走，风格专有的判据与数据写进该风格自己的 `*-series-planner`（`fit-criteria.md` / `domain-kits.md` / 台账）。

## 一、先想清楚的五句话

1. **风格 = 固定语法 × 领域素材。** 找方向就是找"能让这套语法兑现"的领域素材；语法本身不改。
2. **契合再高，没有池深和大众钩子只是四星。** 四星只做穿插单期，不立主栏目。
3. **收藏率是 2026 年平台第一权重**（收藏 > 转发 / 复访 > 完播 > 评论 > 点赞）。选题要自带"以后还要用 / 还要查"。
4. **一期要写得出一个"三元组"**：本风格主配方里最关键的三样东西在这一期分别是什么（深海是 原理 × 证物 × 手边物；诗词长卷可能是 诗句 × 景观 × 情绪转折）。写不出三元组的选题不进库。三元组由本风格 planner 定义（还没定义的见第三节"基线缺件"）。
5. **只决定"做什么"，不决定"怎么像这个风格"。** 风格规则、节奏数字、旁白写法引用风格 skill（`<风格>-style-explainer`）的节号，不抄。本文里的 planner = 选题 skill，explainer = 风格 skill。

## 二、两条方向轴

| 轴 | 切法 | 池深五星线 |
|---|---|---|
| 学科轴 | 按学科 / 专业课 / 考纲 / 题材门类切 | ≥50 期（有考纲、目录托底的天然 100+） |
| 叙事单元轴 | 一期拆一个 X（一件物、一个符号、一首诗、一个人物） | ≥100 期（"入场易、持续难"，100 期是穿过同质化的最低储备） |

同一素材两轴可各讲一次，角度必须不同；和已有方向重叠 >30% 的新方向，建库时逐期比对（第七节）。

## 三、六阶工作流（缺输入先问）

开工前问清：账号阶段、平台侧重、有无点名方向、目标期数（20 / 50 / 300）、有无商单领域、能否联网与派子代理。

| 阶段 | 做什么 | 产出 |
|---|---|---|
| 0 读基线 | 读本风格风格 skill 的哲学、主配方、三层表、作者感觉、`hit-mechanics.md`；读本风格选题 skill 的选题门与台账（已立项的方向）。缺哪样按下面"基线缺件"补 | 缺件时：选题 skill 的 `fit-criteria.md` 补上哲学 / 选题门 / 主配方 / 三层表 / 作者感觉 / 爆点机制 / 口径裁决 |
| 1 找候选 | ≥25 个，跨度要有意外（不许全是安全近邻），每个一句理由；来源见第四节；可按来源派子代理并行 | 候选清单 |
| 2 评级 | 第五节：三否决 → 风格契合 → 爆火六力 → 定星 | 方向评级总表 + 否决清单 + 与已有方向的重叠说明 |
| 3 定顺序 | 零门槛、拥有感强、制作轻的先做；考据长、制作重的后做；形式创意最强的放风格稳定之后 | 立项顺序 + 每方向一句定位 |
| 4 种子包 | 每个五星方向（★★★★☆ 立项时同样做，排在五星后）：≥15 条联网爆款实证（平台 / 账号 / 播放量级 / 可借鉴点）→ 流量结论 → 50 期种子 → 领域套件草案（不写 hex）→ 合规与事实雷区 | `_开工种子包.md` |
| 5 选题池与路线图 | 存量体检（钩子 / 获得感 / 大众度各 1–5，任一 ≤2 判弱）→ 撞题扫描 → 分簇分季排到目标期数 → 可持续性 + 自补给线 | `_选题路线图.md` |
| 6 交接 | 每个方向一条任务消息（第八节），交给生产线 | 任务消息 |

**只看风格契合、不看池深与钩子的评级无效。** 阶段 4 的联网实证只能在 Kiro / Cursor 做；Pi 里标"待联网查证"。

**基线缺件（老风格 skill 常见）。** 不改风格 skill（explainer），缺的东西补在本风格的选题 skill（planner）里（还没有选题 skill 先建一个，见 `SKILL.md` ⑥ 第 1 步）：

| 缺什么 | 怎么补 | 写到哪 |
|---|---|---|
| 哲学与选题门 | 按 `style-foundations`「哲学怎么读出来」从风格 skill 的规则、拒绝项和发明倒推；每条对上两条规则 | `fit-criteria.md` 开头「哲学」「选题门」两节 |
| 主配方（风格 skill 只有信念句，或"主配方"标题下写的是哲学） | 从风格 skill 的结构 / 拍型 / 步骤节倒推一条时序主线；信念句移到「哲学」 | `fit-criteria.md`「主配方」一节 |
| 作者感觉与作者感觉对照 | 按 `style-foundations`「作者感觉」从哲学 + 本质压出，五项（想法 / 画面 / 节奏 / 旁白 / 声音）各 1–3 条"他会……，不会……"，再写每项问什么 | `fit-criteria.md`「作者感觉」一节 |
| 三层表 | 按 `style-foundations`「三层分离法」从风格 skill 的规则 / 常量栏拆，四个维度（画面 / 画面节奏 / 旁白 / 声音）；拿不准的放作者默认 | `fit-criteria.md` 开头，每条注明取自风格 skill 哪一节 |
| `hit-mechanics.md` | 从风格 skill 的标杆描述、标题、钩子里整理"为什么有人看"，每条机制对到一条本质 | `fit-criteria.md`「爆点机制」一节；整理不出就写"缺失，六力凭通识打" |
| 三元组 | 风格 skill 主配方的开放槽位取最关键的三个 | 选题 skill SKILL.md「三元组」一节 |
| 台账（已立项方向） | 有产出目录就从目录反推；什么都没有就写"缺台账"，重叠说明标"待查" | planner 台账；交接前补齐 |
| 风格 skill 内部口径矛盾（例：说"配方一拍不变"又允许合并拍；"主配方"标题下写成了哲学句） | 选一种解读，写理由；判不了的放作者默认 | `fit-criteria.md`「口径裁决」一节 |

之后评级、选题、创新都按选题 skill 里补的这份走；等用户同意改风格 skill 时再把它搬回风格 skill。

## 四、候选从哪找

- 学科：高中课本与考纲目录、大学专业目录、国外同类频道的选题表、中文生态空白、生活方式、社科人文、商业金融、体育新兴。
- 叙事单元：博物馆藏品目录、专利库、符号 / 字体 / 颜色史、名作清单（诗、画、建筑）、日用品拆解、地名 / 节气 / 民俗。
- 本风格特有的来源写在它的 planner 里（例：诗词线加"语文课本诗目、文旅城市宣传点"）。
- 留档：每个候选记来源链接；子代理分工时按来源切，不按领域切（避免都挑安全近邻）。

## 五、评级

**1. 三个一票否决（任一不过：出局或降为客串单元）**

| 否决项 | 检验 | 不过的处理 |
|---|---|---|
| H3 可生产性 | 这个领域的素材能不能按本风格的产线做出来？（A 线：能否按本期运动规则写成可控时间码事件，并保住必要的起态、可见过程与终态；B 线：能否写成 H3 能出的镜头）关键表现依赖哪些尚未验证或尚未接入的能力？ | 没有当前可控路径时否决或标待验证；可解析不等于已出片成功 |
| 合规安全 | 医疗诊断 / 用药、荐股 / 保险比价、政治民族、未定案人物指控、地图国界、赌博技巧？能否改切角？ | 能改切角就改，改不了否决 |
| 池深 | 学科轴 ≥50、叙事轴 ≥100？用"枚举法"证明：列出该方向所有**本风格能演的**单元，再数能配的素材 | 不到线：封顶 ★★★★（客串单元，挂在相邻方向下），不单独立方向 |

**走哪条轴、用哪条池深线**：看"一期的单位"是什么，不看有没有考纲。一期讲一个知识点 / 原理，能直接从考纲或教材目录列出来 → 学科轴（≥50）。一期讲一个完整的 X（一个故事、一件物、一首诗、一个成语），哪怕这些 X 在课本里 → 叙事轴（≥100），考纲只算枚举来源。拿不准按叙事轴（线更高，从严）。

**2. 风格契合**：先过选题门（从风格 skill 的哲学导出，2–4 道，深海是四门；任一道不过 = 明显短板），再把本风格三层表里"本质"每一条（画面、画面节奏、旁白、声音都算）改写成一个 1–5 分的问题（"这个领域能不能兑现这一条"）。进五星要**每项 ≥4 且平均 ≥4.5**；任一项 ≤3 就是"明显短板"。深海的五项（视觉字母表 / 变形潜力 / 案例阶梯 / 锚点辨识度 / 概念密度）加"四门"就是这样来的，见 `shenhai-series-planner/references/rating-rubric.md`。新风格的判据写进它自己的 `fit-criteria.md`。契合题只从本质出，作者默认和每期自由不进契合题。

**3. 爆火六力（每力 1–5）**

| 力 | 检验问题 |
|---|---|
| 认知冲击力 | 看完第一句会不会"啊？" |
| 拥有感 | 观众会不会想"这东西我有 / 我去过 / 我背过" |
| 闭环快感 | 问题 → 线索 → 答案在片内闭合吗 |
| 留存价值 | 会不会点收藏"以后用"（2026 第一权重） |
| 分享动机 | 有没有明确的"转给谁" |
| 形式创意 | 形式和内容是不是同一件事（形式本身就在讲这个知识）；这种表达别的栏目有没有 |

上面的检验问题是按"有旁白的知识片"写的。本风格没有旁白、或片长很短时，在本风格 `fit-criteria.md` 里**改写检验问题**（例："看完第一句"→"第一帧 + 平台标题"；"问题 → 线索 → 答案"→"起 → 转 → 收在片内闭合"），力的名字和下面的星级线不改。fit-criteria 里有改写版就按改写版打分，并在评级表口径里写一句"六力按 fit-criteria 改写版"。

**4. 定星（判定树，从上往下，命中即停）**

"满分"= 5 分。"池深在线附近"= 学科 50–70 / 叙事 100–120。

1. 可生产性不过，或合规改了切角也讲不了 → **出局**，进否决清单（写理由，防止重复评估）。
2. 契合任一项 ≤3（明显短板），或改切角后本方向最强的钩子不能讲了（合规受限）→ **★★★ 及以下**：不立项，记理由。
3. 池深不到线 → **★★★★**：客串单期 / 子系列，挂在相邻方向下，不建文件夹。
4. 以下全满足 → **★★★★★**，立主栏目，建文件夹与种子包：
   - 契合每项 ≥4 且平均 ≥4.5；
   - 六力 ≥4 项满分，且没有一项 <3（留存价值 <3 最常卡在这里：其余全满分也不进五星）；
   - 池深高于"在线附近"，有枚举依据。
5. 其余条件都够五星，只差下面其中一条 → **★★★★☆**，可立项，排在五星后：
   - 六力只有 3 项满分；
   - 池深只在线附近；
   - 契合每项 ≥4，但平均在 4.0–4.4。
6. 其余（六力满分 ≤2 项、六力有一项 <3、或同时差两条及以上）→ **★★★★**：客串单期 / 子系列。

一个风格评了一整批都没有五星时，先查两件事再下结论：六力问题是不是没按本风格改写（见上段）；契合题是不是混进了作者默认。两样都没问题，结论就是"本风格当前没有能立主栏目的方向"，照实写，不放宽星级线。

## 六、每期字段

期号 / 标题 / 一句话钩子 / 核心内容 / 三元组 / 主锚点 / 爆款指数（1–5）/ 钩子类型 / 创新档 / 查证要点。

- **主锚点**：这一期画面上承载内容、观众认得出的那件具体东西，从本方向的领域套件里选（深海：领域锚点套件里被选中的那件；靠转场串场的风格：跨所有转场存活的那件）。本风格 planner 可在 `fit-criteria.md` 里改写取法。
- **爆款指数**：对这一期的整体流量判断，不是六力求平均。5 = 全民钩子（不懂领域也会点）；4 = 强（有明确人群会转发）；3 = 稳（垂类内常青）；2 = 垂类（只有学过的人在意）；1 = 养号（补完整性）。第 1 期必须是 5。

钩子类型（每期至少一种）：考试刚需、日常好奇、拥有感、反常识、热点搭桥（不追突发）、决策工具、情绪共鸣（诗词 / 故事类）。

创新档：A 按配方直走；B 母题创新（全片贯穿一个图形或镜头装置，数字不动）；C 形式即内容（调用 `creative-animation-treatment` 整片模式；只许改每期自由，作者默认最多偏离 1–2 条并写理由，再多就是风格变体，回研发线 ⑤）。三档写完都过作者感觉对照。

标题：按本风格的标题习惯（写在 planner 里）；通用底线是短、有悬念或反差、不用"今天讲……"，第 1 期永远是本方向最强钩子。

## 七、撞题与可持续

- 撞题扫描：和所有邻近方向的种子包逐期比。撞了三选一：分工保留（各讲一侧，片尾互导）/ 替换（换镜像题）/ 收窄（让出重叠段）。不允许两边都讲一遍。
- 可持续：给出剩余版图概算（还能枚举出多少单元）+ 自补给线（生产中冒出的余料回流到 `_故事素材库.md`，展开下一批前先扫它）。
- 池深虚高的信号：说 300 期，前 20 个单元就开始重复角度。

## 八、交给生产线的任务消息

一条任务消息 = 一个方向，整段可复制进 Pi 或新对话。骨架：

```text
【角色】你是「<风格>」栏目【<方向>】的制作人。
【必读】h3-director（Pi 自动带）；风格 skill <风格>-style-explainer 全文与全部 references
       （哲学、作者感觉、旁白写法 narration.md 都要读，旁白照它写）；
       A 线写稿时同时读 h3-storyboard-writing（§0 管中文画面怎么写才做得出来），
       B 线写稿时同时读 h3-prompt-writing 与 h3-director「多镜头线出片」；
       本方向种子包 <路径>；选题路线图 <路径>。
【锁定参数】工作目录 <系列根>；画布与强调色的推导理由（不写 hex）；领域锚点 3–5 件；
           时长与画幅；特殊红线。
【每期】按路线图逐期：三元组、钩子类型、创新档、查证要点；原稿按风格 skill 的交付格式写、写完过作者感觉对照，
       不写 H3 提示词（A 线由 h3_timecode 生成）；所有事实先联网查证并留档。
【停点】前 3 期做完停下等用户确认，之后按批推进。
```

深海线的完整版（含必读编号、字数口径、铁律）见 `shenhai-series-planner/references/output-templates.md` 第五节。

## 九、全局合规红线（评级和选题都要过）

1. 金融：只讲机制，不荐股、不比价具体保险产品。
2. 医疗：不做诊断 / 治疗 / 用药指导；急救只讲原理并注明不替代线下培训。
3. 地图：不出现精确国界；用拓扑节点图或无国界色块。
4. 体育：战术与规则可以画，动作示范不做。
5. 人物：在世企业家不做人身化叙事；未定案指控不做；传说桥段标"待核"。
6. 品牌：机制讲透，不点名在售型号做导购对比。
7. 版权：真实作品 / logo 矢量重绘表达，现行商标不 1:1 复刻；宗教 / 政治符号不做。例外：商单品牌方书面授权的自家 logo / 商标，按授权范围使用，授权文件留档；授权外的第三方商标仍按本条。
8. 历史 / 诗词：作者、年代、原文逐字核对权威版本；存疑的写"一说"。
