# 四份报告的提纲、必填数与子代理提示词骨架

本文里"风格 skill"= `<slug>-style-explainer`，"选题 skill"= `<slug>-series-planner`。

口径：技能 `style-foundations` 的 `references/measurement-protocol.md` 与六把尺子（节奏读数的口径注意 measurement-protocol §8：脚本是 scene_score，产线目标是像素口径）。每条结论带时码（`MM:SS.mmm` 或帧号 + 片 ID）；说不准写“证据不足”，多支片报范围（最小–最大）+ 中位。“样本未见”不等于作者刻意拒绝；“从不做/不说”注明已看样本范围，证据不足不升成风格硬红线。

一个风格 = 画面 + 画面节奏 + 旁白 + 声音，外加把它们串起来的哲学。四份报告分别管：

| 报告 | 管什么 | 进风格 skill 的哪里 |
|---|---|---|
| 01 视觉美学 | 画面长什么样 | `style-dna.md` Part A 画布 / 色彩 / 构图 / 图形语言 |
| 02 节奏与剪辑 | 画面怎么动怎么停、旁白的快慢停顿、两者怎么咬合 | `style-dna.md` Part A 画面节奏 / 声画咬合、`beat-templates.md`；旁白节奏进 `narration.md`；汇总进 SKILL.md「节奏」 |
| 03 旁白写法 | 怎么说、说什么顺序、从不说什么（无旁白风格写朗诵 / 字幕 / 音乐）；观众在每一处被要求做什么（参与层） | `narration.md`（含「参与」节）+ SKILL.md「旁白写法」 |
| 04 风格解构（核心，最后写） | 哲学、主配方、三层表、作者感觉、爆点机制 | SKILL.md「哲学」「主配方」「作者感觉」「三层表」；`style-dna.md`「哲学（证据版）」「三层表」、A0 通用尺子取舍表；`hit-mechanics.md`；选题门进选题 skill `fit-criteria.md` |

01 / 02 / 03 可以并行；04 等前三份写完再写。

**文章来源（公众号等）也写这四份**，填法：01 写版面与配图（小标题、配图、加粗、引用块的用法；没有就写"不适用"）；02 写阅读节奏（开头 300 字做了什么，各部分在全文的百分比，转折 / 高潮 / 金句落在哪，段落长短怎么交替）；03 就是写法本身，按 `narration-rulers.md` 逐节写，外加考据方法（资料从哪来、数字怎么用、怎么交叉印证）；04 照常。三层表的画面 / 画面节奏 / 声音三行写"由研发线 ③ 配的画面提供"；可以多加"选题""结构""考据"三行。证据写"篇名 + 第几段"代替时码。旧风格线只有 01 视觉 / 02 节奏 / 03 风格解构三份的：不重命名，旧 03 按本文 04 读；升级时新增 `03b_旁白写法分析.md`，并在 `目录说明.md` 注明对应关系。

## 01_视觉美学分析.md

1. 画布：底色白 / 黑 / 中占比、颗粒、光源（从 `analysis_report.md` 画布行抄数，再用联络表描述）
2. 色彩：彩色面积 p50 / p90、同屏色相数、强调色首次出现时刻与所在词；实测 hex 列表只作证据
3. 构图：主体位置、留白、禁区（字幕带 / 角标区）、层次
4. 图形语言：线宽、形体、材质、有没有人物 / 手 / 脸
5. 文字：屏上字的版式、出现方式；字幕（原片有没有、在哪一带）
6. 通用尺子读数：构图 / 配色 / 画布声音三把尺子逐维度四态（采纳 / 改造 / 拒绝 / 不适用）

## 02_节奏与剪辑分析.md

**画面节奏**
1. 节拍表：逐段重建（起止时码、旁白句、画面事件、音效）
   对承担机制或转折的动作，补“起态 → 触发/阻力 → 可见过程 → 终态 → 下拍怎样继承”；区分主动作、被它引起的反应和背景活动。不能只记出入场名词或事件数。
2. 事件：事件/分；四档占比；滑动 p50 / p90；运动时间占比
3. 静止：p50 / p90 / 最长；≥3 s 静止次数；最长静止落在哪句
4. 切换：硬切/分；镜长 p25 / p50 / p75；0.10–0.30 跳变逐个核对结论（重构图 / 切）
5. 节奏型：全片的"静 → 动 → 静"起伏画成一条线（按 10 s 分窗数事件），高潮在全片百分之几；每段内部的起伏是否重复同一个形状

**旁白节奏**（口径见 `narration-rulers.md` 第一节）
6. 旁白：句数、字/句 p25 / p50 / p75、字/秒（出声 / 全片两个数）、停顿 p50 / p90、≥1 s 停顿次数与位置、首句时刻、旁白覆盖率、句群（几句一组）

**声画咬合**
7. 事件/句、零事件句占比、事件落点（开口 / 句中 / 停顿内）、偏移中位（负 = 画面先动）；声画关系归类（旁白领画面 / 画面领旁白 / 声画反相 / 同步）
8. 音乐与音效：有无 BGM、分段、拍速（能量得出时）、音效与事件的对应
9. 运动尺子读数：迪士尼 12 法则 / UX 动效词汇逐条四态；接缝判问（`motion-rulers.md` 4b）

暗场、细线小字、没有旁白（屏下字幕当旁白）的片子，整帧帧差会严重低估运动：按 `measurement-protocol.md` 7b 分带量（字幕带墨量分段得字幕起止与读速、音频起音补过程事件），报告里整帧读数标"不可信"；脚本报的硬切先按 7c 排除"构图不动的整屏亮度脉冲"。

## 03_旁白写法分析.md

按 `style-foundations/references/narration-rulers.md` 逐节写。没有旁白的片，把"旁白"换成它实际的语言层（朗诵的诗句、屏上文案、歌词、音乐的段落结构），不适用的维度标"不适用"。

1. 句法：句型占比（陈述 / 设问 / 反问 / 感叹 / 祈使）、问号个数与位置；最常用的 2–3 个句式，每个抄 3 句原文；人称；口头禅用不用
2. 修辞：比喻（喻体来源、一期几次）、反差翻转、数字与实物、重复回扣、感官词、金句（句式、位置）
3. 结构：开场句型（用哪几种、从不用哪种）、段落推进方式与转场句原文、术语出现在演示前还是后、收尾方式、固定口播原文、高潮句位置
4. 口吻与人设：讲述者像谁、表演性高低、可信度装置；"内容不变、只换掉口吻，作者感觉还在不在"的判定（本质 / 作者默认）
5. 行业做法对照：`narration-rulers.md` 第七节逐条四态；拒绝的写补偿
6. **逐字样例 ≥15 句**：覆盖开场、转场、高潮、收尾、固定口播，每句标时码和它示范的手法
7. **从不说的话**：逐条可判定（例："不说'大家好'""前两句没有问号"）
8. 写稿公式：把 1–7 压成"写一期旁白的步骤"（先写哪句、每段几句、每句多长、在哪放金句），能让没看过片的人照着写
9. **参与层**（按 `style-foundations/references/participation-rulers.md` 第八节必交五项）：逐句参与类型表与统计（接收 / 预测 / 解题 / 跟玩 / 自体实验 / 比较 / 回忆 / 反省 / 交还，首次出力时刻）、思考留白列表 + p50（留白时有没有等待物）、命名先后表、参与风险判定、回扣物与交还句原文。讲解 / 科普 / 教学类片子必写；纯叙事或纯音乐片写"不适用"并说明观众在做什么

## 04_风格解构.md（核心）

1. 通用尺子取舍总表（汇总 01 / 02 / 03 的四态）；**"拒绝"单列一节**：拒绝了什么、用什么补偿
2. **哲学**（方法见 `style-foundations`「哲学怎么读出来」）：3–7 条"作者相信 X → 所以 Y（规则，证据）"，合成一句话；导出 2–4 道选题门。先写草稿；第 6 项三层表写完后回来逐条核对，每条对不上两条规则的删
3. **主配方**：一句可复述的时序主线（动作链 + 硬指标 + 变量分配），包含上述动作机制与承接；画布材质、配色和出现/消失不能独自构成配方。“少即是多”这类信念句归哲学；找不到就回去补看。分别注明原片机制、可控生产改写、未出片验证方案，避免生产默认变成原片结论
4. 格式层：整期结构（几段式、各段时长占比、开场与收束的固定写法）
5. 执行标准：画布 / 色彩 / 构图 / 运动 / 文字 / 旁白 / 声音，每条写「服务配方哪一环 · 与通识的关系 · 实测数字（来源片）」
6. **三层表**（方法见 `style-foundations` 三层分离法）：本质 / 作者默认 / 每期自由，**四个维度都要有条目**：画面、画面节奏、旁白、声音（某维度某层确实没有，写"无"并说理由）；03 的参与层读数也分进去（例：让观众先做再命名、题必中或答不出即答案——通常是本质；留白秒数、问号个数——通常是作者默认）。每条注证据；每条问两问：换个题材它还在吗 / 去掉它作者感觉还在吗。选题判据从本质和选题门来，风格创新只动后两层
7. **作者感觉**：哲学 + 本质压成"他怎么想、怎么看、怎么动、怎么说"，按想法 / 画面 / 节奏 / 旁白 / 声音五项各 1–3 条（与作者感觉对照一一对应），每条写成"他会……，不会……"（例："旁白：他会用陈述句 0.3 s 就开口，不会先问观众问题"）；再写本风格的作者感觉对照（想法 / 画面 / 节奏 / 旁白 / 声音各问什么，方法见 `style-foundations`「作者感觉」）
8. 红线：作者从不做的事，逐条可判定（画面和旁白都算）
9. 产线路线建议：A 配音先行时间码线 / B 多镜头线，附依据数字
10. **爆点机制**（与风格分开）：前 3 秒给什么、揭示 / 反差时刻放哪、记忆点、结尾、选题池深度
11. 反例自检：拿每条规则去找打脸的帧，找到就改

## 子代理提示词骨架（Kiro / Cursor 并行时用）

```text
你是参考片分析员，只写一份报告：<01 视觉美学 | 02 节奏与剪辑 | 03 旁白写法 | 04 风格解构>，中文，写到 <风格线>\视频分析\<文件名>.md。
素材（只读）：
- 原片：<路径列表，含片 ID>
- 量化读数：<风格线>\视频分析\分析素材\analysis_report.md / .json（汇总）；每支片子目录 <片 ID>\ 有 meta.json、frames\、sheets\（联络表）、transcript.json（有旁白时）、scene_raw.txt / scene_crop.txt（逐帧差分）
- 帧时刻：按 analysis_report.md 每片的「帧时刻」行换算（frames\f_NNNN.jpg 与联络表格子都没有印时码）
- 口径：技能 style-foundations 的 references\measurement-protocol.md 与六把尺子（写 03 必读 references\narration-rulers.md 与 references\participation-rulers.md；写 02 时暗场小字 / 无旁白片按 measurement-protocol 7b 分带量）
- 提纲：技能 h3-research-director 的 references\report-outlines.md 对应一节
规则：每条结论带时码证据；多片报范围；数字只抄报告或自己用 ffmpeg 复测（写明命令）；旁白原文以 transcript.json 为底、逐字听校，ASR 错字要改正并注明；实测 hex 只作证据；不要改原片、skill 和别的文件夹；不要再派子代理。
结尾：≤200 字摘要（本报告最强的 3 个读数、证据不足的项；04 再加哲学一句话与主配方一句）。
```

04 必须等 01 / 02 / 03 写完再派；把三份报告的路径列进素材，允许它回读 `analysis_report.md`、`transcript.json` 和联络表核对。
