# 风格创新：在已学的风格上长出新风格

前提：② 已产出哲学、主配方、三层表（本质 / 作者默认 / 每期自由，四个维度：画面、画面节奏、旁白、声音）、作者感觉和作者感觉对照（方法见 `style-foundations`）。没有三层表不做创新——分不清哪条能改，改出来的不是新风格就是走样。

目标是**创新之后还有作者的感觉**：新画面、新母题、新方向、新比喻都可以，只要做法是他的——作者本人拿到这个新点子，会不会就这样做。新的是"做什么、用什么"，守的是"他怎么想、怎么做"。守住作者感觉靠两样：哲学和本质一条不动（程度 1、2）；做完逐项过作者感觉对照。旁白也在三层表里，创新可以换旁白的作者默认（例：句群长短、比喻来源），不能换旁白的本质（以本风格三层表为准；深海例：口吻、开口方式）。

本文里"风格 skill"= `<slug>-style-explainer`（explainer），"选题 skill"= `<slug>-series-planner`（planner）。

## 一、先判断是哪一种

| 程度 | 动了什么 | 结论 | 落到哪 |
|---|---|---|---|
| 1 期级创新 | 每期自由层；或带理由偏离 1–2 条作者默认 | 还是原风格 | 母题进原选题 skill「创新档与母题库」的 B 档母题库；偏离作者默认的进原风格 skill「创新档怎么执行」的允许的偏离；C 档每期现场做，不登记 |
| 2 风格变体 | 哲学与本质全保留，换一组作者默认（2–4 项） | 原风格的一个分支，可以单独立栏目 | 新的一对变体 skill（`video=<原slug>-<变体>`）；变体选题 skill 的 fit-criteria 基线写"继承 <原选题 skill>"，只登记变体下重评的方向与台账 |
| 3 杂交 / 新风格 | 改了某条本质或哲学，或把两个风格的本质拼在一起 | 新风格（有意离开原作者） | 写出新的哲学和主配方后，从研发线 ③ 起完整走一遍 |

判断口诀：**哲学和本质没破 = 还是他；作者默认换了一批 = 他的变体；本质或哲学改了 = 新风格。**

## 二、怎么找候选

**1. 变体生成（程度 2）**：列出作者默认层的每一项（画布、材质、主色策略、运动质感、镜头、声音层、结构顺序……），对每一项问"换成什么还能兑现全部本质"。操作子从 `creative-animation-treatment/references/catalog.md` 取，按作者默认的类别找轴：

| 作者默认的类别 | catalog 轴 |
|---|---|
| 材质 / 媒介 / 画布 | A Material / medium |
| 空间 / 维度 | B Space |
| 时间（快慢、倒放、定格） | C Time；S Time as matter |
| 转场 / 变形 / 连续性 | D Transform |
| 镜头 / 视点 | F Camera |
| 图形 / 版式 / 字 | G Graphic；T Writing |
| 声画关系 | H Sound-image |
| 运动质感 | K Motion craft |
| 画框 / 舞台 / 演出传统 | M Stage |
| 工艺过程 | U Craft grammar |
| 结构顺序 / 留人节奏 | X Attention（只做辅助，必须配一个 A / B / D 动词） |

其余轴（E 修辞、I 混合、J 约束游戏、L 魔术、N 物理现象、O 信息物、P 做了再毁、Q 记谱、R 感知、V 规则、W 生命过程）多用来找母题或杂交方向。全表见 catalog 各轴标题；退役条目和陈词黑名单也在那里，选中了要写对策。一次换 2–4 项，换得太少是期级创新，换得太多容易碰到本质。

例（示意，不是结论）：深海的本质以 `shenhai-style-explainer/references/style-dna.md` B-0 三层表为准（不要从别处的转述里抄）。把它作者默认里的"矢量扁平 + 纸面画布"换成"剪纸层叠 + 台灯光斑"（A 轴，A18 剪纸）、把"无阴影"换成"单一投影"（光源类作者默认，按 `creative-animation-treatment/references/feel.md` 第二节"画布是有光的地方"写），B-0 的本质一条不破 → 可能是一个"深海·剪纸暗室"变体。

**2. 杂交（程度 3）**：拿两个已有风格的三层表并排，从 A 取本质的一部分、从 B 取另一部分，写得出一条新的主配方才算数。例（示意）：望海潮的"一句诗 = 一个镜头"本质 + 深海的"演示先于命名" → 可能是"诗句拆解"新风格，但要重新定产线（多镜头还是时间码）。

**3. 从方向反推（任意程度）**：契合题只从本质出，作者默认不进契合分。所以要找的是：契合分高，但**六力或 H3 可生产性被某一条作者默认拖低**的方向（例：作者默认"无旁白"让留存价值上不去；作者默认"15 秒单段"让闭环讲不完）。这种方向往往就是某个变体的最佳土壤——记下"哪条作者默认拖低了哪一力"，回这里试换掉那一条。拖低它的是本质，就只能走程度 3。

## 三、变体卡（每个候选一张，存 `<风格线>\风格量产\_风格创新_变体卡.md`）

```markdown
### 变体：<中文名>（<slug>）  程度：1 / 2 / 3
- 来源风格：<原风格>（杂交写两个）
- 保留：哲学逐条、本质逐条（画面 / 画面节奏 / 旁白 / 声音）列出，每条一句"在变体里怎么兑现"
- 改动：作者默认 <项> → <新值>，理由：<为什么这样还成立>
- 爆点机制：原风格的留人机制在变体里还成立吗？哪条变强、哪条变弱
- 最适合的方向：从 ④ 评级表挑 1–3 个，说明为什么它比原风格更适合
- H3 可生产性：走 A 线还是 B 线；motion_rule / 补偿要不要重新标定；有没有 H3 做不出来的东西
- 节拍盲测：纯文字节拍表，时长按原风格（或新主配方）的原生时长，不固定 30 秒；写出主体起态、触发、可见过程与终态承接，检查创新是否改变了演出机制，而不只是换材质和名词
- 风险：最可能走样成什么
```

## 四、五问筛选（程度 2、3 必过，全过才立 skill）

1. **哲学和本质没破？**（程度 2）/ **新哲学、新主配方写得出来？**（程度 3）
2. **作者感觉还在？** 逐项过作者感觉对照（想法 / 画面 / 节奏 / 旁白 / 声音，每项问"他会这样做吗"）：程度 2 五项都答得出"会"，才还是原作者的变体。程度 3 是有意离开原作者，不要求原作者的感觉，要求新风格有自己的：用新哲学写出它的作者感觉，并且变体卡里的样例都符合。
3. **有可验证的 H3 实现？** 至少写出 1 段按产线格式的原稿：A 线过 `h3_storyboard action=set` + `h3_plan_durations dry_run=true`，B 线过 `h3_lint`（同研发线 ⑦），并列出关键动作证据与未测风险。这只证明可解析/可编译，动作执行与画面品质写“待出片验证”。当前环境跑不了免费工具：这一问写“待验证”，本轮结论最多“暂不立”。核心动作必须依赖尚未接入的功能时不能算当前可生产；已具可控路径可立待试片方案，不能称实测成功。
4. **有地可种？** 比的是**六力和 H3 可生产性**，不是契合分（程度 2 保留全部本质，契合分按定义不变）：至少 1 个方向在变体下六力满分项变多、或可生产性从不过变过，并因此**升到五星**。原风格下是 ★★★★☆、变体下升到 ★★★★★ 也算。整批都没有能升到五星的方向 → 不过。程度 3（本质变了）按新风格重评契合 + 六力：至少 1 个方向进五星，且它在原风格下不是五星。
5. **值得单立？** 和原风格的差异足够让观众当成另一个栏目；不够就降为程度 1，写进原风格的创新档。

**降为期级创新时怎么裁**：程度 1 只许偏离 1–2 条作者默认。从变体卡的改动项里留最新鲜、又过得了作者感觉对照的 1–2 条（几项其实是同一个装置的算一条），其余删掉。母题写进原选题 skill 的 B 档母题库，偏离作者默认的写进原风格 skill「允许的偏离」（按研发线 ⑥ 表，先给用户看），先试 1 期再说。

## 五、立项与验证

1. 过五问 → 按研发线 ⑥ 用 `h3_skill scaffold` 建配对；变体的 style-dna 写清"继承自 <原风格> 的本质"（引用原风格节号，不复制），只写改动项的读数与推导。
2. 变体没有原片可量，改动项的数字写"目标值（待草稿实测）"，不许写成实测值；用户同意后出 2 段草稿，量完回填并去掉"待实测"。
3. 按研发线 ⑦ 做免费盲写验证。
4. 结论（立 / 暂不立 / 降为期级创新）写进原选题 skill「创新档与母题库」的变体与杂交登记，并记进风格线 `目录说明.md`，防止下次重复评估。
