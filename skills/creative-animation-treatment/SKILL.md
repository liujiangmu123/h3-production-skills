# Creative Animation Treatment

把文字或故事变成**有原因、有过程、有后果的动画**。先设计观众看到的变化，再决定媒介、镜头与修饰。判断好坏靠动作的证据和观看体验；层数、提示词长度、自评分不证明画面高级。

本技能交付中文创意交接单。`h3-prompt-writing` 编译英文；A 线再由 `h3-storyboard-writing` 写逐句分镜与工具输入，B 线按 `h3-director` 多镜头线编译。一般制作也要做必要的动作设计，不必等创新档 C。视频研究的变体步骤可按需查本技能的手法库。全库关系见 `视频分析/skill/_skill关系图.md`。

## Hard rules

1. **先守锁定项。** 用户的风格、选题、材质、旁白、时长和作者本质优先。不得为增加制作价值换风格、加角色或改旁白；没有风格锁时也不默认深海或上一期样子。
2. **动作替文字做事。** 写出谁因什么受到限制、怎样改变、留下什么结果。只把名词画出来，再加出现/漂浮/发光，不构成动画演绎。
3. **过程不可被静帧替代。** 若关键意义住在渗透、受力、选择、追赶或展开中，交接必须保留可见过程；不能为事件数好看把它改成“瞬间变成”。原文只需状态对比时，瞬变也可以是正确设计。
4. **材料决定运动。** 同一个意图在纸、墨、黏土、平面图形中有不同动作证据。精确数值/文字/计数先查工具能力；不要让模型猜关键事实。
5. **一拍有一个观看任务。** 可有相连的预备、动作、反应，但不能同时抢多个焦点。镜头帮助观众发现变化；锁机位也能通过主体行动产生丰富动画。
6. **后果进入下一拍。** 变化之后的姿态、位置、材料痕迹或关系要被下一拍继承。回扣应让观众认出“同一个东西现在不同了”，无需整段提示词逐字复刻。
7. **手法是选择，不是配额。** 不强求三档力度、错拍、最长预备停、环境活层、三件道具、一次破色、规则破例或陌生结尾。均匀机械重复、纯白背景和真正静止都可以承担意义。
8. **设计与验证分开。** 纸上方案写“计划/待测”；只有实际样片才写观测结果。模型文档提供表达方法，不保证当前 ComfyUI 工作流能完成每种复杂变形。

## Workflow

### 1. Intake

确认任务文本、观看目的、风格锁、主体/证物、时长画幅，以及 A 线（配音先行时间码）/ B 线（多镜头）/ 尚未决定。用户未指定路线时根据现有风格和动作需求提出方案，不冒称已切换产线。长稿按已有章节设计，缺少信息时先用可解释的假设推进可独立部分。

有 `participation-design` 拍表时保留其已锁定的等待、揭晓、命名位置；本技能决定这些拍如何被看见，不另写一套互动。没有拍表不强加互动或收藏卡。

### 2. Parse the text

找出**内动词、起态、触发/目标、阻力、终态、观众最后多懂了什么**。叙事可用角色愿望和选择；演示用物理/逻辑限制；抽象动画可用空间关系。不要把所有东西拟人化。

先写一行因果骨架，如“重复压平 → 墨触及折缝 → 原折缝阻住下一次压下 → 折层改为展开 → 原机器留下树的结构”。每个箭头应能由画面解释。隐喻可夸张，但不能凭空换掉需要认出的主体。

### 2b. Decide the register（保留旧锚点）

按 world-class.md §一选择 R1 符号 / R2 关系图 / R3 场景 / R4 材料 / R5 电影空间。它们是信息住所，不是高低分。只回答本题真正有区分力的问题：什么必须被看见？换成点框会失去什么？光或材料是否在证明结论？

锁定风格时在其允许范围内选；没有档位规则时以其本质和参考画面为边界并注明假设。不能只凭本技能重写风格。简单图形只要有可读的动作因果，也能完成高级设计。

### 3. Diverge before you browse

先提出少量**不同机制**：改变主体目标、改变阻力、让材料特性介入、换观察者、颠倒因果顺序或减到一个物件。只换颜色/材质名称的不是独立创意。短拍不强制八个发散动作或五至八个候选；长片才扩大比较。

用 animation-design.md 的候选表比较“核心机制 / 不可替代的动作证据 / 情绪转折 / 风格与实现风险”，选一个并说明最接近方案为何落选。不得用虚高自评分代替判断。

### 4. Pick operators

因果成立后按需查 catalog 的内动词与转场索引。保留帮助动作成立的手法，删掉只增加效果量的手法；一个足够鲜明的机制可以单独成立。

逐关键动作判断 H3 / 精确后期或代码 / 混合。当前 H3-pi-agent + ComfyUI 是否已有执行入口，以工具支持和配置为准。需要尚不存在的代码层时给出 H3 原生替代和损失，未有制作授权不安装软件、不开始生成。

### 5. Native-render the metaphor

写成“意图 → 该材料如何行动 → 哪个旧特征穿过变化”。例如纸折层沿原折线展开，墨沿纤维吸入，图形边界改变包含关系；不要用通用黑团溶解替代所有形变。

### 6. Commit to the action design

给每个关键拍写动作设计表：主体与起态、触发/目标、可见过程（路径/速度/材料反应）、终态及下一拍继承、焦点/镜头、实现路线与风险。只写影响效果的细节；不逐秒塞新东西。

复核空间因果：触发点与受影响物若不在同处，观众要看见传递的路径、接触或规则证据；“脚边鼓起，所以压头停了”还需说明鼓起怎样影响压头行程。跨拍物件换位置也要有可见来路，身份不变不能代替运动路径。结尾小特征须在实际景别可读，不能远退后只靠文字说它仍在。

另列**不可丢的动作证据**：这拍若只保留起终两张静帧，观众会失去什么？若答案是“什么也没少”，检查它是否本来就是状态比较；不要为满足表格硬加中间动作。

### 7. Craft pass（感觉层）

按本片需要挑诊断，不逐层加配料：主焦点是否明确；重量是否体现在起落而非形容词；时间留给过程还是等待；材料是否接触/受力；反应是否体现结果；声音是否帮助因果；镜头是否揭示新信息。风格禁止的写法不用。

纸上描述只能做默放检查。中间动作帧不必都是海报；灰度也不是颜色演示的替代验收。参照作品只写具体借用的方法和差异，不宣称“已达到同级”。

### 7b. A-line feasibility（配音先行）

读 world-class.md §五 A 线与 `h3-storyboard-writing`。默认锁机位、段界重放、事件起点、`until`、`motion_rule`、`hold_en` 等以**当前工具和本期 style 配置**为准，深海默认不是所有 H3 动画的上限。

瞬变适合读状态；短复合动作要在同一事件内可见地完成；连续动作必须有可容纳的有效时窗，不能只写“渐渐”却仍调用瞬变/强制静止的配置。`until` 不跨旁白句；跨句过程需改为稳定的动作里程碑，或提出兼容的 B 线方案。若编译必然丢掉证据，回到设计选等义动作或报告具体损失，不能悄悄压缩。

### 7c. B-line feasibility（多镜头）

读 world-class.md §五 B 线。交接中文分段意图、主动作与关键中间态，最终英文字段由 `h3-prompt-writing` 编译。镜头可固定或运动，必须有观看理由；分段时长、续接/剪接和模型任务按 `h3-director` 及实际工作流确认，不把“约10秒”当已校验参数。

### 7d. Flow pass（连续性）

每段写 `A → B → C` 并说明位置/方向/主体/声音/意义继承了什么。换镜可故意断空间，只要观众理解为什么；不规定断链次数。跨生成段交接旧主体的身份、末态、机位关系、光和下一拍起点。按 flow.md §六检查段界重放与终态稳定。

### 7e. World-class gate（旧名保留，现为创意审稿）

按 world-class.md §三作证据审稿：因果能否看懂；过程是否不可替代；时序与材料是否成立；焦点与连续性是否清楚；重要锁定项和实际路线是否兑现。记录“成立 / 需改 / 待样片证实”及具体依据。不填满八层、不以 ≥24/30 自评当放行证明。

### 8. Audience pass（仅任务需要时）

检查开场提出的问题是否诚实、正文是否兑现、结尾是否带来理解或回响。知识片可考虑可复用的规则或图解，叙事片可用动作结果；不强加评论诱饵或收藏物。不得编造平台推荐算法权重、固定秒数或完播阈值，也不为钩子改锁定旁白。

## Whole-film mode（整片语言）

先定整片因果、主要身份锚、必要的媒介/空间/镜头规则，再把段落写成**建立关系 → 使原关系遇到变化 → 让结果被看见**，也可以按叙事需要使用其他结构。每段承担不同观看任务，避免各段都是一个孤立图解。

母题在回归时改变功能或意义。高潮可能是一个选择、一次停止、关系揭晓或大动作；不强制三级升级、规则破例、先闪结局、最大动作前最长停。锁定风格的哲学与本质保持，作者默认的可变范围由它自己的三层表决定；需越界的变体交研究线。

## Output format

输出按任务规模裁剪。**最小交接必须有下列字段**；候选可简短比较，已选定方向则直接设计。短拍不生成整部片的无用表格。

```markdown
## 这段的内动词 / 一句话
## 风格与产线
锁定项、档位及理由；A/B/待定；实际能力尚未确认处
## 候选样子 / 采用
不同动作机制的比较；选择与落选理由
## 因果骨架
起态 → 触发/限制 → 可见改变 → 结果 → 后续影响
## 不可丢的动作证据
逐关键拍写：必须看见哪一个过程；瞬现会损失什么
## 动作设计表
| 主体与起态 | 触发/目标 | 可见过程（路径/速度/材料反应） | 终态及下一拍继承 | 焦点/镜头 | 实现路线与风险 |
|---|---|---|---|---|---|
## 视觉语言 / 动量链
只列本片必要的材质、身份、观看和节奏规则；每段如何接下一段
## 交接
A：锁定旁白原句 → 中文视觉意图；动作时窗/静止终态；风格配置冲突
B：段 N、目标净时长、起态/主动作/必要中间态/终态、镜头理由、声音
## 创意审稿（原“世界级门槛”） / 风险
成立的证据、需改处、待样片验证处；不以文字自评分声称已验证
```

这些是**Markdown 设计字段，不是 h3_timecode 的 JSON 键**。下游只能用实际 schema 允许的字段。需要时追加旧兼容字段：媒介、世界与住户圣经、形变/空间、时间/镜头/其他、原生演法、为什么它证明这段文字、视觉语言四条、活层、表演、颜色关系、色彩剧本、招牌镜头、间、参与位、看不见的细节、删掉的默认、声音怎么帮、参照与偏离、制作路由与分层、转场清单。不要无条件填满，不写最终英文提示词或伪时间码。

编译后对照“不可丢的动作证据”，如果主体、因果、过程、结果被删或被 `instantly`/强制 hold 覆盖，应修正路由/动作/配置并报告；不能只检查风格词有没有复制。

## When the user rejects the winner

- “没创意 / 见过”：换动作机制、目标或阻力，勿仅换媒介。
- “没感觉”：查事件是否有后果、时间是否让过程被感知、材料是否受力；再决定预备/反应/停顿，勿自动补光和漂浮。
- “太简单”：先辨别欠缺的是信息、动作还是空间；必要时在风格允许范围补证物。无需自动升档。
- “像 PPT”：检查是否只有出现、换色、消失，编译有没有压掉动作过程；用继承的状态连接关键拍。
- “做不出来”：保留意义和关键证据，减少同时变化的部件或换稳定里程碑；明确损失与待测。
- “跟系列不搭”：复核锁定风格与本期规则，收回越界，而非重写风格技能。

## When a style is already locked

读其哲学、本质/作者默认/每期自由三层表、产线路线、旁白与声音规则和作者感觉对照。哲学、本质与用户指定项保持；每期自由处设计本期动作。默认偏离是否允许由该风格决定，不能将本技能的“可选”当成越界许可。任何冲突写出原要求、方案和代价；本轮维护不修改风格或选题技能。
