# 世界级层 —— 制作价值诊断（沿用旧文件名）

本文件帮助判断缺了什么，不认证“世界级”。R1–R5、八层和历史对标是观察维度；不得强制加满，不再使用 ≥24/30 放行。简洁和丰富都要服从题意、锁定风格和实际路线。

## 〇、“中等”长什么样（先认症状）

动作只有出现/换色、变化没有原因、主体没有受到影响、同一套运动可换任何题、过程被编译压掉、镜头忙却未揭示信息，都是应调查的症状。纯白、无阴影、均匀节拍、静止或少物件本身不是缺陷。先找可见证据缺口，再决定补动作、关系、材料或空间。

## 一、画面档位尺 R1–R5（信息住在哪里）

| 档位 | 合适的观看任务 | 主要证据 |
|---|---|---|
| R1 符号 | 对比、命名、单关系变化 | 位置、边界、包含、数量关系 |
| R2 图解 | 系统、路径、流程与结构 | 连通、阻塞、流向、状态 |
| R3 场景 | 人与环境的关系、事件 | 空间、行动、因果、反应 |
| R4 材料 | 材料特性参与意义 | 接触、受力、形变与痕迹 |
| R5 电影空间 | 视点、景深或镜头承担叙事 | 遮挡、发现、距离与观看顺序 |

五问按需使用：住所问（知识住在哪里）、替换测（点框会失去什么）、质感测（材料是否证明意义）、情绪测（通过什么动作关系被感到）、证物测（真实证据能否辨认）。不必逐题填表；情绪不自动要求 R3 以上。锁定风格的本质和合法范围优先，范围未知写假设，不替风格补一套规定。

## 二、世界级八层 + 招牌镜头（按需诊断）

### 1. 世界 World
空间中什么对因果有用？身份定义只保留重复主体必要的比例、材料、位置关系和特征。无需固定三至六组道具或四层景深。

### 2. 光 Light
有实体场景时确认光源/方向/明暗关系是否帮助阅读；纯平面风格可以无实体光。实际灯源与无原因 glow 装饰不同，不一律禁止光效，也不一律要求单灯。

### 3. 材质 Material
重量与受力是否通过中间态和落定显现？纸折层、墨纤维、黏土凹痕、图形边界应各用自己的动作，不靠贴材质词。

### 4. 生命 Life（活层）
环境运动只在支持地点、情绪或故事时选；零环境运动也成立。A 线持续运动可能干扰帧差定位，不能靠“面积很小”文字保证通过，见 §五。

### 5. 表演 Acting
人物/物体的目标、限制、选择与反应有无可见证据？眼→头→身是可选注意顺序，不是所有角色必走的动作。无角色不硬加表情。

### 6. 调度与镜头 Staging & camera
一个观看任务是否可读？运动或切点让观众发现了什么？静镜同样可用。A/B 真实约束不同，禁止以 A 默认否定 B 的能力。

### 7. 声音 Sound
声响能否证明接触、阻力、空间或节拍改变？可用拟音/环境/音乐，也可安静；数量和静音位置由内容决定。旁白、口型和音频字段守下游规则。

### 8. 色彩剧本 Color script
颜色是否区分状态、关系或注意？锁定色规则优先。颜色演示不能用灰度通过代替色彩信息的验收，不强制首次强调色或仅一次破色。

### 9. 招牌镜头 Signature moment
若片子需要关键镜头，写其前提、不可丢的动作证据和改变的结果；可以很小、很静。不固定三件物体、最长预备停或最大幅度。

## 三、世界级门槛（Step 7e：证据审稿）

| 判问 | 写什么依据 | 不成立怎么改 |
|---|---|---|
| 因果 | 触发、限制和结果可由什么画面连接 | 补必要接触/选择/路径，删无关变化 |
| 过程 | 两张静帧会损失哪条意义 | 保留中间态；本是状态比较则不硬加动作 |
| 时间与材料 | 哪个时序/受力/痕迹承载感觉 | 调整相对时序、受力和结果停，不套统一缓动 |
| 焦点与连续性 | 观众如何找到变化、认出旧主体 | 减同动层、锁身份、写下一拍继承 |
| 兑现与可做性 | 风格、事实、工具配置是否相容 | 修动作/路由，明确损失或待测 |

用“成立 / 需改 / 待样片证实”标状态。纸上默放和智能体试写是设计验证；影片要靠实际样片验收。没有样片不能宣称动作、对齐、审美已经通过。

## 四、对标作品库（借方法，不评同级）

需要参照时可选具体作品：Saul Bass 片头的图形意义、3Blue1Brown 的关系演示、Laika 的材料受力、Spider-Verse 的时序与媒介变化。说明借哪一处方法、服务本题什么、不借何种造型/情节。没有合适参照可以不填，不用作品名替代动作设计。

历史来源与本地研究入口见 sources.md；不把某作者的方法设为其他风格的本质。

## 五、落到 H3（Step 7b / 7c：实际路线）

### A 线（配音先行、时间码）

- 确认本期 style 和工具版本。默认锁机位、瞬变/静止、节奏与段长是特定产线配置，不能同时承诺无缝长动作却不调整相冲突的配置。
- 起点/音效/事件预算和稳定段尾以 `h3-storyboard-writing` 为准。动作证据可在短复合事件中完成；连续过程用有效 `until`，它不能跨旁白句。默认强制 hold 会在事件后追加，需明确它对应动作完成后的状态。
- 大于一句时窗的过程拆稳定里程碑；若这样仍丢题意，给 B 线或等义动作方案。不要冒称只改一个“渐渐”形容词就支持了。
- `h3_align` 用灰度缩放/模糊后的帧间变化来测部分事件，持续移动可能导致假阳性或找不到独立 onset。不能把物体几何面积或“背景轻微”当保证；连续动作用看片/关键帧确认中间态，指标适用性另报，不为了低帧差把世界冻住。
- 段界重放与首事件保护窗按当前工具计算。上一段尾应处于可继承稳定状态，续段引用旧主体，不在重放窗安排新揭晓或剪切。
- 精确文字、数字与事实使用实际可用后期/代码能力；未接通时明确风险与替代。

### B 线（多镜头 T2VA）

- 按 `h3-director` 确认任务、段长、镜头与 latent 续接/独立剪接；不从 A 线搬来锁机位或瞬变限制。
- 在有效时段写主动作的连续发展、中间态与结果，动作和运镜同时复杂时减低非必要变化。
- 切点和机位为新的观看信息服务，不固定一段两至四镜或每镜恰好一次运动。
- 采用 latent 续接时首段重放保护仍生效；与另起片段剪接的规则分开。稳定锚比重新叙述全场更有利于保住身份，但一致性仍需实际看片。
- 英文字段、时间语法、首尾参考图任务按 `h3-prompt-writing` 官方规则；本技能交中文意图，不抢编译工作。

### 官方风格包的路线

官方样例和提示词指南可作研究，不表示本地当前工作流已支持所有示例任务。可核实入口：MiniMaxAI/MiniMax-H3 的 docs/VIDEO_PROMPT_WRITING_GUIDE_base_en.md。模型原始指南与本地 A 线限制分层阅读。

## 六、自测

对照 §三逐条给证据；短拍选关键项。检查用户/风格锁、不可丢过程、跨拍终态继承、真实时窗和待测标记。若问题出在意义或动作，不以加光、加生命层、升 R 档来代替修因果。
