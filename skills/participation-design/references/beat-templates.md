# Beat 模板（按片长与用途选择）

这些组合是设计起点，按锁定风格、题材和实际阅读时间调整。比例与章数只描述样例；不把每种环节缩放后塞进所有片子。

## 0. 局部与短片

- **一处参与**：题面/待完成动作 → 给观众尝试 → 可见反馈 → 必要解释；若本期只审一拍，就只交这四件事。
- **短片单闭环**：一个能直接看懂的预测或比较 → 过程暴露差异 → 结果确认；命名、回扣或交还按内容需要选用。
- **已有稿审查**：找出被旁白抢答的一处，改成先给线索与动作证据再确认；不重排整片。

## 1. 可选长片骨架（4–6 分钟、多章参与式样例）

| 位置 | 段 | 阶梯 | 推荐装置 | 要点 |
|---|---|---|---|---|
| 0–8% | 冷开场 | L1+L2 | D22（D01/D02）+ D08 | 一个能做成、一个做不成；仪表 6 s 内出现 |
| ~8% | 片名 | — | — | 片名在第一次惊奇之后 |
| 8–65% | 章 1…N（4–6 章） | L3→L6 逐章上升 | 见 §2 | 每章一个回扣物或仪表复现 |
| 高潮段（样例约70%） | 高潮 | L6 | D20/D21 | 最大翻转；视觉力度按风格，满屏色是可选方案 |
| 75–90% | 回到生活 | L7 | D29 → D30 | 仪表量生活；最长留白 |
| 90–100% | 交还 | L8 | D31（+D32） | 开头物件原样回来，片名收 |

## 2. 可选章模板（按概念删选）

```
[入口] 让你做：D04/D05/D13/D15…        留白 2–6 s，等待物：＿＿
[外化] 画出你的状态：D08/D09/D10        每步 1–2 s
[揭晓] 动作结果/形变/比较/光色/声音       时长按风格与动作需要
[命名] 数字 → 名字 → 公式/人名（D27）    1.5–2 s
[推远] 零门槛生活例 / 历史               2–4 s
[翻转] 观众刚建立的判断（D20）           前置 1 s 静
[种子] 下一章的问题（D26）               1 s
```

## 4. 模板句

- 填空：「＿＿＿＿＿＿」（空格发光）
- 出题：「你只能＿＿。最少要＿＿？」

- 自体实验：「读一下这句。」……「你读懂了，因为＿＿。」
- 命名：「这个，就叫＿＿。」
- 翻转：「＿＿不是＿＿，它是＿＿。」
- 先对后大：「你猜对了。可＿＿比你以为的＿＿。」
- 推远：「＿＿之所以＿＿，是因为＿＿。」
- 种子：「＿＿。可＿＿呢？」
- 反省：「今天你＿＿的东西里，有多少是＿＿？」
- 交还：「这一次，由你来＿＿。」

## 5. 有旁白版的 beat 改写

| 无旁白 | 配音版 |
|---|---|
| 字幕出题，下屏答 | 旁白念题 → 静 → 画面揭晓 → 旁白后半拍确认 |
| 填空 2–4 s | 旁白停在空格前，不念答案 |
| 自体实验材料 | 只在屏上，旁白只说"读一下" |
| 反省 + 8 s 光标 | 旁白念题后整段静 |
