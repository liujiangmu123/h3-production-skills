# 参与装置库（32 种）

字段：**心理**＝触发机制 ｜ **写法**＝屏上/旁白写法 ｜ **时长**＝留白/在屏 ｜ **题材** ｜ **实现**＝H3/代码动画要点 ｜ **反例**。
功能标签 L0 接收、L1 预测、L2 预测失败、L3 解题、L4 跟玩、L5 亲身实验、L6 判断、L7 反省、L8 交还；可重复或跳过，不要求按次序走完。
标 ★ 的在《信息论·惊奇之学》原片出现过。
「实现」是候选方案，按本期风格与已接工具选择。H3 A 线冻结块用静止等待状态；呼吸/闪烁等活层会干扰整帧差质检，需由动画设计与分镜说明风险和人工动作证据。精确倒计时/字形交代码或后期；当前未接入的层要标待实现。

## A 预测类（L1–L2）

**D01 填空 ★**（L1）
- 心理：生成效应；补字即预测，揭晓即反馈。
- 写法：「床前明月＿」；空格用比正文亮的金色下划线。
- 时长：揭晓前 2–4 s。
- 题材：任何有确定短答案的事实、常识、诗句、公式。
- 实现：代码层画空格与落字；H3 只负责揭晓时的光晕。
- 反例：空格答案有多个合理值却按一个揭晓 → 观众觉得被冤枉。

**D02 补不出的填空 ★**（L2）
- 心理：预测失败本身就是知识（"失败即答案"）。
- 写法：同句式第二次出现，候选字一直滚、永不揭晓。
- 时长：3–5 s，可贯穿全片。
- 题材：随机性、不确定性、未解之谜、个体差异。
- 实现：代码候选滚动（老虎机），滚速先快后慢不停。
- 反例：最后偷偷揭晓一个答案 → 毁掉"不可预测"的论点。

**D03 下一项是什么**（L1）
- 心理：模式补全；规律被看见即理解。
- 写法：「1, 1, 2, 3, 5, ＿」
- 时长：2–3 s。
- 题材：数学、自然规律、历史周期、语言规律。
- 实现：代码排列数列，空位发光。
- 反例：需要专业知识才猜得到 → 门槛太高。

**D04 先选再看（二选一 / 三选一）**（L1）
- 心理：承诺效应；押了注揭晓才和你有关。
- 写法：「哪个先落地？ A 铁球 B 羽毛（真空中）」
- 时长：2–3 s，选项轻微呼吸动画。
- 题材：物理直觉、生物、经济选择、历史决策。
- 实现：H3 画两个对象，代码写 A/B 标签。
- 反例：选项一眼看出"老师想要的答案" → 没有真实押注。

**D05 估一个数 ★**（L3）
- 心理：信息缺口；估错不丢人，误差即惊奇。
- 写法：「最少要问几次？」+ 发光问号。
- 时长：4–6 s。
- 题材：数量级、概率、距离、时间。
- 实现：问号或刻度尺缓慢发光；揭晓数字放大 + 同心圆。
- 反例：要求精确计算 → 观众放弃。

**D06 拖动的刻度 / 押注条**（L3）
- 心理：把估计外化为位置，揭晓时看见自己与真相的距离。
- 写法：屏上一条刻度尺，指针游移后停在"多数人以为的位置"，再滑到真值。
- 时长：3–5 s。
- 题材：统计、比例、天文尺度。
- 实现：代码画尺与指针；真值处用光标定。
- 反例：直接给真值不给"以为的位置" → 无对比。

**D07 预言后验证（时间快进）**（L1）
- 心理：预测误差；先说"你觉得会怎样"再放过程。
- 写法：「冰块放进盐水，会更快化还是更慢？」→ 快进实拍/动画。
- 时长：2 s 押注 + 过程。
- 题材：化学、物理、生态、社会实验。
- 实现：H3 画过程，代码叠计时器。
- 反例：过程太慢、结果不明显。

## B 状态外化类（让观众看见自己脑子里正在发生的事）

**D08 活体仪表 ★**
- 心理：自我量化；第一次看见内在状态被测出来，仪表成为"镜子"。
- 写法：小仪表「惊奇 ≈0 bit」→「? bits」；最后一次量观众的生活。
- 时长：常驻小角，读数变化时 0.5 s 强调。
- 题材：任何可量化的感受（风险、咸度、熟悉度、确信度）。
- 实现：代码层；同一视觉语言全片复用。
- 反例：仪表量的是抽象物而非观众刚经历的事 → 只是图表。

**D09 剩余可能计数 ★**
- 心理：把不确定画成可数的东西，看它缩小。
- 写法：「剩余 512 种可能」+ 被排除的一半变暗红。
- 时长：每步 1–2 s。
- 题材：搜索、诊断、推理、进化筛选。
- 实现：代码网格/数轴 + 计数器。
- 反例：只有数字没有区域变化，或反之。

**D10 候选滚动不揭晓 ★**
- 心理：持续的未决感 = 不确定性的体感。
- 写法：空格里候选字/数字一直滚。
- 时长：可长时间常驻。
- 题材：随机、量子、未来预测。
- 实现：代码。
- 反例：滚得太快看不清，失去"候选"感。

**D11 置信度条**
- 心理：元认知；让观众意识到自己有多确定。
- 写法：押注后出现「你有多确定？」条从 50% 慢慢涨。
- 时长：2 s。
- 题材：认知偏差、统计、谣言辨析。
- 实现：代码。
- 反例：要求观众真的回答 → 视频不能交互，改成"多数人 80%"。

## C 跟玩与亲身实验类（L4–L5）

**D12 跟玩游戏（前慢后快）★**（L4）
- 心理：规则→进度→终点；加速让规律浮现。
- 写法：「第 1 问：大于 512 吗？」计数器 + 位串。
- 时长：前 3 步各 2 s，后面 <1 s。
- 题材：算法、博弈、进化、扩散、复利。
- 实现：代码驱动状态；H3 可出结局的光。
- 反例：全程匀速 → 观众看不见规律。

**D13 乱序/残缺阅读 ★**（L5）
- 心理：自体实验；先完成后被揭穿。
- 写法：「研表究明，汉字的序顺并不定一能影阅响读」完整出现，读完再逐字跳位。
- 时长：读字时长 + 1 s。
- 题材：语言、冗余、认知补全。
- 实现：代码文字；绝不能用 H3 画中文。
- 反例：先告诉观众"下面是乱序的" → 实验失效。

**D14 遮挡/噪声中照样读懂 ★**（L5）
- 心理：鲁棒性的亲身证据。
- 写法：句子被红块一个个盖掉 + 标签「仍然读得懂」。
- 时长：3–4 s。
- 题材：纠错、冗余、免疫、网络韧性。
- 实现：代码遮挡块。
- 反例：遮到真的读不懂 → 实验失败。

**D15 视错觉/知觉实验**（L5）
- 心理：最强证据是"你刚才自己"。
- 写法：「盯着中间的点 20 秒」→ 看白屏余像。
- 时长：按实验要求，配等待物（倒计时环）。
- 题材：视觉、神经、注意、色彩。
- 实现：代码/H3 均可，精确图形用代码。
- 反例：依赖屏幕亮度/设备，部分人看不到。

**D16 身体参与**（L5）
- 心理：具身认知；动一下的知识记得牢。
- 写法：「摸一下你的脉搏，数 10 秒」+ 计时环。
- 时长：实测时长。
- 题材：生理、物理（转笔、平衡）、听觉。
- 实现：代码计时器。
- 反例：需要道具或站起来 → 多数人不做。

**D17 记忆小测（先看后提取）**（L5）
- 心理：提取练习 + 自我参照。
- 写法：闪现 7 个词 3 s → 「刚才有'床'吗？」（其实没有）。
- 时长：闪现 3 s + 提问 2 s。
- 题材：记忆、虚假记忆、注意。
- 实现：代码。
- 反例：题目设计成人人都中招却嘲讽观众。

## D 判断与翻转类（L6）

**D18 并排对照「哪个更＿？」★**（L6）
- 心理：比较判断一眼完成，差异即概念。
- 写法：左乱码 / 右「春风又绿江南岸」，「同样 112 bits」。
- 时长：2–3 s。
- 题材：艺术、设计、电影构图、两种解法。
- 实现：H3 出两种画面，代码标签。
- 反例：两边差异需要专业眼光。

**D19 换字/换参数试验 ★**（L6）
- 心理：what-if 探索（explorable explanations 的视频版）。
- 写法：诗里"绿"依次换成 到/过/入/满，最后落回"绿"。
- 时长：每换 0.8–1.2 s。
- 题材：参数敏感性、措辞、配方、物理常数。
- 实现：代码替换；H3 可随参数变色调。
- 反例：换的选项太多太快。

**D20 翻转：你以为没用的 ★**（L6）
- 心理：对刚建立判断的预测误差（误概念暴露）。
- 写法：「冗余不是浪费，它是铠甲。」
- 时长：翻转句前 1 s 静。
- 题材：几乎所有（噪声、病毒、失败、无聊）。
- 实现：画面同一物件换光/换色，不换物件。
- 反例：翻的是观众没建立过的判断 → 无冲击。

**D21 先对后大（押对再放大）**（L6）
- 心理：确认的快感 + 尺度惊奇，无挫败。
- 写法：「你猜对了。可这件事比你以为的大一千倍。」
- 时长：1 s 静 + 放大镜头。
- 题材：天文、生物数量、历史影响。
- 实现：H3 拉远镜头。
- 反例：放大不真实或无数据支撑。

**D22 两个同构小实验 ★**（L1+L2）
- 心理：一个能做成一个做不成，对比本身就是本期核心。
- 写法：「床前明月＿」/「窗外下起了＿」。
- 时长：各 3–5 s，冷开场 ≤20 s。
- 题材：所有（开场专用）。
- 实现：同一版式、同一位置，观众一眼知道"同构"。
- 反例：两个实验形式不同 → 对比不成立。

## E 节奏与悬念类

**D23 出题 + 计时留白 ★**
- 心理：信息缺口需要时间才转化为思考。
- 写法：问题单独一屏 + 发光问号。
- 时长：章首 2–6 s。
- 题材：通用。
- 实现：等待物慢光；有旁白时旁白在此静音。
- 反例：死黑无动 → 观众以为卡了。

**D24 问答同屏自答 ★**
- 心理：半秒自答，降低章内小问题成本。
- 写法：「烽火为什么值得点？」半秒后「因为敌人很少来。」
- 时长：0.5–1 s。
- 题材：通用章内。
- 实现：代码逐行出。
- 反例：每个小问题都留长白 → 拖沓。

**D25 破折号悬句 ★**
- 心理：未完成感驱动看下一屏。
- 写法：「发射功率只有二十瓦左右——」下屏接。
- 时长：0.5–1 s。
- 题材：后半句是数字或反转时。
- 实现：跨屏切。
- 反例：后半句平淡。

**D26 章末种子 ★**
- 心理：每章最后一句是下一章问题的种子，无需"接下来我们讲"。
- 写法：「能传过去。可传过去的，有意义吗？」
- 时长：1 s。
- 题材：通用。
- 实现：字幕层。
- 反例：显式目录式过渡。

**D27 名字后置 ★**
- 心理：标签贴在已有体验上。
- 写法：体验 → 数字 → 「这个，就叫比特。」→ 人名年份小注。
- 时长：命名句 1.5–2 s。
- 题材：通用。
- 实现：术语用强调色，人名用小号注释。
- 反例：开头先抛术语。

## F 回扣与交还类（L7–L8）

**D28 回扣物 ★**
- 心理：认出来 = 一次猜中的预测；第二次换意思产生整体感。
- 写法：烽火：敌情 → 值得去找的新东西。
- 时长：每次 2–4 s。
- 题材：通用。
- 实现：同一构图/同一物件，换光或换上下文。
- 反例：回扣但意思不变 → 只是重复。

**D29 镜子照到生活 ★**（L7）
- 心理：自我参照效应。
- 写法：仪表最后量观众的推荐流：「2.46 → 0.02 bits」。
- 时长：3–4 s。
- 题材：通用，尤其技术与社会。
- 实现：同一仪表视觉语言。
- 反例：生活例是作者的不是观众的。

**D30 反省问题 + 最长留白 ★**（L7）
- 心理：私下作答，无评判。
- 写法：「今天你看到的东西里，有多少是你没有料到的？」+ 光标。
- 时长：6–8 s，全片最长。
- 题材：通用。
- 实现：只剩光标/慢光；有旁白时整段静。
- 反例：问题有标准答案 → 变成考试。

**D31 交还空格 ★**（L8）
- 心理：共同作者；结尾是交接不是结论。
- 写法：开头的空格原样回来：「这一次，由你来填。」
- 时长：3–5 s 后片名。
- 题材：通用（片尾专用）。
- 实现：与开头同构图同位置。
- 反例：交还后又补一句总结 → 收回了笔。

**D32 行动邀请（离开屏幕的实验）**（L8）
- 心理：把实验延伸到现实，提取练习发生在片外。
- 写法：「下次坐地铁，数一数报站里你猜得到的字。」
- 时长：2–3 s。
- 题材：通用，生活化题材最佳。
- 实现：字幕层。
- 反例：要求成本高（下载、购买、登记）。
