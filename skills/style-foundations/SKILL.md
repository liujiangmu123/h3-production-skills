# 风格分析通用尺子（行业通识层）

## 定位：尺子，不是规范

本技能存放**与任何具体风格无关的行业公共理论**——迪士尼动画 12 法则、UX 动效词汇、构图法则、色彩理论、画布与声音惯例、旁白与文案写法。它们是**分析用的尺子**，不是必须遵守的规范：

> **风格 = 在通用尺子上的一组特定读数与取舍。**
> 有的作者采纳法则，有的改造，有的刻意拒绝——**拒绝往往是最强的风格签名**（深海拒绝"次要动作"造出死寂律；唐伯虎拒绝"挤压拉伸"造出真纸测试）。"不用"也是一种读数，必须被记录。

## 三个用途

1. **分析新标杆视频时当尺子**：在四层塔提取之前，先对照六把尺子（运动、构图、配色、画布与声音、旁白与文案、参与）逐维度标注该作者的态度（采纳/改造/拒绝/不适用）+ 帧证据。这保证不漏维度，并把"作者拒绝的通识"逼出来。
2. **风格 skill 的取舍登记**：每个风格 skill 的 style-dna Part A 首节（A0）放一张「通用尺子取舍表」，登记读数与取舍；**教科书内容不复制进风格 skill**——通识留在本技能，风格文件只放该风格自己的东西（量化读数、取舍声明、作者发明）。
3. **创作时的兜底词汇表**：某风格 skill 对某维度没写规则时，把本技能的通识当候选词汇，由本期表达目的决定，保持与已有取舍兼容；不要求把所有法则加进每支片。

测量回答“动了多少、何时动、用了什么形式”；导演判断还要看“变化是否有因果、是否承担概念/情绪、过程是否可读、结果是否推动下一拍”。高密度、墨量或色面达标不能代替表达判断，补充生成设计交给 `creative-animation-treatment`，本尺子不规定更多元素才更好。

## 四态判定法（分析时逐条执行）

| 态度 | 判定 | 记录要求 |
| --- | --- | --- |
| **采纳** | 作者按行业通识原样使用 | 一句话 + 证据帧即可，不必展开 |
| **改造** | 用了，但变形（参数极端化 / 方向反转 / 语境移植） | 必须写清**变形处**——变形处就是风格 |
| **拒绝** | 行业都做而他刻意不做 | 必须写清**拒绝了什么 + 用什么机制补偿**——这是风格最强信号 |
| 不适用 | 该维度与此媒介无关（如实拍片谈挤压拉伸） | 标注即可，不算拒绝 |

四态是对**已获证据的取舍**分类，另记证据状态：已观察 / 样本未见 / 证据不足。单支片里没出现的手法只写“样本未见”，不推断作者意图；只有反复可比较的取舍或明确设定支持时才记“刻意拒绝”。“从不做”要注明已看样本范围。

## 三层分离法（尺子对照之后做，选题和创新都靠它）

把一个风格的每条规则分进三层，每条附证据帧。**四个维度都要分**：画面（长什么样）、画面节奏（怎么动、怎么停）、旁白（怎么说、按什么顺序说；没有旁白的写朗诵 / 字幕 / 音乐）、声音（音效与配乐的分寸）。只分了画面的三层表，创新时会把作者的口吻和节奏改丢。

| 层 | 判定 | 选题时 | 创新时 |
| --- | --- | --- | --- |
| **本质** | 换任何题材都不变；破了一条，作者的感觉就没了 | 每条改写成一个契合问题（"这个领域能不能兑现这一条"） | 不动；改了就是新风格 |
| **作者默认** | 作者的习惯做法，量得出稳定读数，但换个题材换掉也不致命 | 不作判据 | 风格变体换的就是这一层（一次 2–4 项） |
| **每期自由** | 每期现场推导（具体颜色、母题、案例、锚点） | 决定每期的素材 | 期级创新（创新档 B / C） |

判定方法：对每条规则问"换个题材它还在吗""去掉它，作者的感觉还在吗"。换题材它还在、去掉它感觉就没了 → 本质；去掉它感觉还在，但读数稳定 → 作者默认；每期都不同 → 每期自由。本质候选需跨题材一致证据或用户明确锁定；样本不足标待复核，拿不准先放作者默认，别把习惯、未见手法或生产默认升成本质。此方法用于分析新证据，不自动重评或改动已锁定风格。

完整实例由研发线 `h3-research-director` 指（本技能是尺子，不引用任何风格文件）。好的本质格同时写得出注意力设计、画布、色彩、图形世界、讲授顺序和声音口吻。

## 哲学怎么读出来（四层塔最上一层）

哲学 = 作者相信什么，所以他这样做。它比规则高一层：规则说"一次只动一件东西"，哲学说"克制是注意力设计，不是审美"。

1. **从帧和旁白里读，不从口号读。** 作者自己说的"少即是多"不算；看他做了什么、拒绝了什么。
2. **从"拒绝"和"发明"倒推。** 每条拒绝背后有一个信念（拒绝次要动作 ← 相信注意力只能给一件东西）；每个发明是一个信念的装置。
3. **每条写成"作者相信 X → 所以 Y（规则，证据片 + 时码）"**，3–7 条。每条至少对上三层表里两条规则；对不上的删掉，那是你的感想，不是他的哲学。
4. **合成一句话**：能让没看过片的人复述出这个作者（就是风格 skill「哲学」节开头那一句）。
5. **导出选题门**：对每条哲学问"什么题材做不到这一条"，得到 2–4 道门（例（仅示格式）：一个讲原理的作者可能有"能从一个最小单位讲起""能演出来"这样的门），交给选题 skill 当契合判据。

## 作者感觉（创新时要守住的东西）

作者感觉 = 作者**怎么想、怎么看、怎么动、怎么说**的那股劲，来自**哲学 + 三层表的本质**，落在想法 / 画面 / 节奏 / 旁白 / 声音五项上（想法对应哲学，后四项对应三层表的四个维度）。创新改的是"做什么、用什么"（题材、母题、画面元素、比喻、结构装置），作者感觉守的是"他怎么想、怎么做"。

判断标准不是"观众能不能认出这是他"，而是：**如果作者本人拿到这个新点子，他会不会就这样做。** 一期可以出现他从没画过的东西、从没用过的比喻，只要做法、分寸、口吻是他的，作者感觉就在；反过来，元素全照搬他的，做法变了，作者感觉照样会丢。

**作者感觉对照**（创新方案做完、写完一期都逐项问一遍"他会这样做吗"）：

| 维度 | 问 | 走样的样子 |
| --- | --- | --- |
| 想法（哲学） | 这个新点子出自他相信的东西吗？他会这样想这个题吗？ | 点子本身违背他的信念（例：作者相信克制是注意力设计，创新却让两样东西同时动"更丰富"） |
| 画面 | 新画面是用他的眼光组织的吗：主体、留白、克制程度、对材质的态度 | 元素是新的，分寸不是他的（更满、更炫、更甜） |
| 节奏 | 动和停的呼吸还是他的吗 | 被新点子带快、拖散，或高潮放错了地方 |
| 旁白 | 新内容是用他的口吻、句式、先后顺序讲的吗 | 讲的东西新了，腔调成了别人的 |
| 声音 | 声音的分寸是他的吗 | 音效变多变响、配乐抢戏 |

五项都能答"他会这样做"，才算有作者感觉。某项不过，先改"怎么做"，不砍新点子本身；只有点子本身违背哲学，才换点子。

## 与四层塔的关系

```
四层塔：哲学层 → 格式层 → 风格词汇层 → 题材槽位层
                      ↑
        地基（第 0 层）：通用理论层（本技能）
```

风格词汇层的每条规则都与地基有一种关系：**采纳 / 改造 / 拒绝 / 发明**（发明 = 通识里根本没有的作者独创装置，如深海的"心电图节奏"命名、唐伯虎的"仪式色收尾盖印"、望海潮的"美感四查"）。分析报告须把四种关系分开呈现。

## 使用流程（分析新视频时）

1. 读六把尺子（一次通读，建立维度清单；有旁白、朗诵或屏上文案的片，旁白与文案尺子必读；讲解、科普、教学类片子参与尺子必读）；
2. 先按 `references/measurement-protocol.md` 量（裁字幕带逐帧差分 → 事件四档 + 静止分布 → 联络表逐张看），再逐维度记读数：作者在这个维度上做了什么？态度是四态中的哪种？证据帧 + 数字？
3. 输出「通用尺子取舍表」：维度 | 态度 | 该风格的形态 | 证据；**"拒绝"行单独提出来重点分析补偿机制**；
4. 取舍表之外剩下的、通识里找不到对应维度的手法 → 那就是**作者的发明**，进入四层塔的哲学层与风格词汇层重点提取；
5. 草拟哲学（上文「哲学怎么读出来」）；第 6 步三层表做完后回头核对，每条对不上两条规则的删；
6. 做三层分离（上文「三层分离法」，四个维度都分），得出本质 / 作者默认 / 每期自由三层表；写出作者感觉（五项各 1–3 条"他会……，不会……"）与本风格的作者感觉对照（上文「作者感觉」）；
7. skill 落盘时：哲学、主配方、三层表、作者感觉进风格 skill SKILL.md 对应节，证据版进 style-dna 开头；选题门进选题 skill `fit-criteria.md`；取舍表进 style-dna Part A 首节（A0）；量化读数进约束数值；旁白读数、句式、逐字样例进 `narration.md`；发明写成该风格的专属律条。整条研发流程见 `h3-research-director`。
