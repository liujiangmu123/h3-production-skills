# 参与尺子 — Participation Rulers（行业通识；分析时逐条问）

用途：分析一支片时，量出**作者让观众在脑子里做了什么、什么时候做、做不出来会怎样**。有旁白、无旁白（屏上文字当旁白）、纯音乐片都过这张尺子；本文件只放判问，不存任何风格的读数。生成侧（怎么设计参与、装置库、写法）在共享技能 `participation-design`，这里不复制。

量的素材：旁白的 `transcript.json` 或屏上文字全文（无旁白片先把屏上字按时间抄全）+ 联络表。每一处都带时码。

## 一、每一句在让观众做什么（参与类型）

逐句（或逐个屏上大字）标一类，统计句数与按段 / 章分布：

| 类型 | 观众在做什么 | 识别 |
| --- | --- | --- |
| 接收 | 只读 / 只听一句陈述 | 默认档 |
| 预测 | 在答案出现前心里补出它 | 残句、空格、"下一个是……"、停在半路的旋律 |
| 预测失败 | 想补，补不出——补不出本身是要讲的点 | 第二个残句、候选不揭晓 |
| 估算 / 解题 | 给出一个数或一个选择 | 问句 + 留白；"你猜……"；投票 |
| 跟玩 | 跟着一步一步走一个有规则的过程 | 计数器、进度、二分、排序 |
| 自体实验 | 观众自己的感官或大脑当证据 | 读乱序句、看错觉、记一串数、听两遍 |
| 判断 / 比较 | 在两样东西里挑一个 | 并排两画面、A/B |
| 回忆 | 调出一段生活经验 | "你一定见过……" |
| 反省 | 想自己的生活 / 选择 | 关于观众本人的问题 |
| 交还 | 结尾把一个动作或问题留给观众完成 | "这一次，由你来……"、留给观众的实验 |

判问：主动出力（预测以下各类）占几成？首次出力在第几秒？全片有没有"逐段加码"（越往后要观众出的力越大）？

## 二、思考留白

| 量什么 | 口径 | 判问 |
| --- | --- | --- |
| 出题 → 揭晓间隔 | 题面出现（或问句结束）到答案出现 / 内容往下走的秒数 | 给不给时间？p50 多长？随全片变长还是变短？ |
| 留白期间的画面 | 有没有"等待物"（静止发光体、闪烁光标、悬停的问号） | 留白是死黑 / 卡住，还是"片子在等你"？ |
| 留白期间的声音 | 静音、铺底、还是过程音 | 安静是给思考的，还是只是没做声音？ |
| 抢答 | 旁白 / 字幕在画面揭晓之前就说出答案 | 有没有把观众要做的事替他做掉？ |

## 三、命名先后

逐个列术语、公式、人名、年份、作品名：出现时刻 + 它之前观众有没有一个可以被它命名的体验。判问：是"先体验后命名"还是"先名字后解释"？例外在哪、有没有理由（新名词挂在刚学会的名词上，也算有体验）？

## 四、参与的风险

- 判问：观众答不出来，会觉得是自己的错吗？（考试题 / 有标准答案且答错丢脸 → 有风险）
- 每一处主动出力归三类：必中 / 失败即答案 / 需陪玩（片子会陪他做完）。有没有第四类"可能失败且没人兜底"？
- 实验是否一定成功（乱序句一定读得懂、错觉一定看错）？依赖观众屏幕、耳机、听力、文化背景的，记为条件实验。

## 五、回扣与交还

- 回扣物：哪个物件 / 句子 / 画面出现 ≥2 次？第二次意思变了没有？
- 交还：结尾把什么留给观众？是邀请（可做可不做）还是号召（关注、点赞）？
- 首尾：开场的实验在结尾有没有原样回来？

## 六、密度与分布

- 每段 / 每章真要观众出力的点几个（多了像考试，少了像讲课）？
- 最长"纯接收"段多长？落在哪里？
- 参与模态几种（读、猜、看、听、动手、比较）？

## 七、行业做法对照（四态）

| 做法 | 判问 |
| --- | --- |
| 开头提问 | 用问号开场，还是用一个不带问号的实验（空格、残句）？ |
| 互动号召（评论区告诉我） | 有没有？是号召还是把真实的未完成动作交给观众？ |
| 小测验 / 选择题 | 有没有？有没有兜底？ |
| "先别急着往下看，想一想" | 有没有口头请观众暂停？还是靠留白让他自然停？ |
| 揭晓用冲击（音效、放大、箭头） | 揭晓靠什么：光、颜色、静、声音、还是冲击？ |

每条标采纳 / 改造 / 拒绝 / 不适用；拒绝的写补偿。

## 八、分析时必交（进 03 报告）

1. 逐句参与类型表 + 统计（类型句数、首次出力时刻、按段分布）。
2. 思考留白列表（出题时码 → 揭晓时码 → 秒数 → 等待物）+ p50。
3. 命名先后表（术语 / 人 / 年份 → 时刻 → 之前的体验）。
4. 风险判定（每处主动出力归哪类）与回扣物、交还句原文。
5. 参与层的三层归类：哪些是本质、哪些是作者默认、哪些每期自由（方法见 SKILL.md 三层分离法）。

示例行（**仅示格式**，不是任何风格的读数）：

```markdown
| 时码 | 句（或屏上字） | 类型 | 留白 s | 等待物 | 备注 |
| 0:02 | 【大字】床前明月＿ | 预测 | 2.4 | 空格微光 | 必中 |
```
