# 参考片帧级测量协议（量化读数的统一口径）

来源：`G:\AI\视频分析\跨风格文档\逐帧核心提炼_跨线对照_2026-09-05.md` §0 / §6（四条线 17 支原片逐帧重看后定下的口径）。统一入口脚本：`G:\AI\视频分析\scripts\analyze_reference.py`（统一入口，见其 `--help`）；最早的一次性脚本在 `设计师深海视频分析\风格分析工作区\深度研究_2026-09-05\`（`frame_rhythm.py` 事件四档 + RMS 停顿 + 咬合、`canvas_probe.py` 画布、`rescore_crop.py` 去字幕带重打分）。

尺子（SKILL.md 六把尺子）告诉你**量哪些维度**；本协议告诉你**怎么量、量出哪些数**。

## 1. 顺序（先量后判，不许反）

1. **裁字幕带的逐帧差分**（scene_score 逐帧打分）
2. **事件四档 + 静止分布**（从差分序列切出事件与静止）
3. **联络表逐张看**（每张带时码；对照差分，确认每个事件"是什么在动"，补上阈值下漏掉的小动作）
4. **结论**（尺子对照表 → 四层塔）

先看图再量，读数会被印象带偏；只量不看，会把字幕换行、镜头呼吸、压缩噪声当成风格。

## 2. 先裁掉底部 16% 字幕带

- 不裁：每一句字幕换行都会被记成一次"运动"。深海第一版没裁，瞬现占比虚高到 **45–62%**，整轮数据作废。
- 做法：打分前 `crop=iw:ih*0.84:0:0`（去掉底部 16%）。字幕在别处（顶部 / 竖排侧栏）就裁那一条；原片无字幕则全帧（如唐伯虎）。
- 报告里写明裁没裁、裁了哪一带。

## 3. 阈值

| 量 | 口径 | 备注 |
| --- | --- | --- |
| 运动帧 | 相邻帧差 ≥ **0.004** | 白底 / 平涂画布的静止噪声 ≈ 0.000–0.002。繁忙画面、颗粒底、实拍**要重调**：先找一段确认静止的镜头量噪声底，阈值放在其 p99 之上 |
| 运动事件 | 连续运动帧，容 2 帧断口 | 按时长分四档（第 4 节） |
| 瞬现 pop | 单帧尖峰 ≥ **0.012** | |
| 硬切 | 帧差 ≥ **0.30** | 低于它的单帧跳变先按第 5 节核对 |
| 静止 | 两事件之间 ≥ **0.2 s** 无运动帧 | |
| 旁白停顿 | RMS 低于（语音 p95 − **28 dB**）且 ≥ **0.25 s** | 先填掉 <120 ms 的假断口（辅音 / 闭塞）；BGM 大时只能当下限 |

## 4. 事件四档

| 档 | 时长 | 读作 |
| --- | --- | --- |
| 瞬现 | ≤ 2 帧 | 元素直接出现 / 变色 |
| 急动 | < 0.3 s | 一下到位 |
| 滑动 | 0.3–1.0 s | 有包络的位移 / 变形（报中位与 p90） |
| 延展 | > 1 s | 描画、生长、长变形链 |

四档占比本身就是风格读数（例（仅示格式）：某风格急动 26–50%、滑动 33–69%、延展 2–14%）。

## 5. 硬切还是重构图

- **单帧跳变 ≤ 0.15、跳变前后共享同一背景 / 底纸 → 画面重构图（recomposition），不是切。**
- 核对：在跳变点前后各 0.5 s 用 **≥ 8 fps** 抽帧，`-ss` 放在 `-i` 之后（output seek，逐帧精确；放在前面会跳到关键帧），逐张看背景是否连续。
- 教训（唐伯虎）：2.396 / 4.188 / 5.563 s 三处 0.13–0.15 的跳变一度被记成"硬切"，报告据此判 skill 的"无硬切"失实；逐帧核对后是同一纸底上的整屏拼贴重组。分数远低于 0.30 本身就是信号。

## 6. 每项测量产出哪些数（报告必填）

| 测量 | 产出 |
| --- | --- |
| 裁字幕帧差 → 事件 | **事件/分**；四档占比；滑动中位 / p90；运动时间占比 |
| 静止分布 | **静止 p50 / p90** / max；≥ 3 s 静止次数 |
| 切换 | **硬切/分**；多镜风格加镜长 p25 / p50 / p75 |
| 旁白（ASR 分句 + RMS） | **字/秒：出声（voiced）与全片（overall）两个数**；**停顿 p50 / p90**；≥ 1 s 停顿次数；句数、字/句 |
| 声画咬合 | 事件起点相对开口的偏移中位（负 = 画面先动）；事件落在句首 / 句中 / 停顿内的占比 |
| 画布 | 底色白 / 黑占比；墨量；**彩色面积占比（colour share）**；色相桶 |

## 7. 已知局限（写进报告）

- 小面积慢动作（细线描画、轻微亮度变化）会落在阈值下 → 靠联络表补。
- ASR 分句 ≠ 语法句；字/秒以出声时长为分母时要注明。
- BGM 大的片子 RMS 停顿只是下限。
- 只看了片头 / 部分片段的，标"部分覆盖"。

## 7b. 暗场、细线小字、字幕当旁白的片子：分带量

整帧帧差会严重低估这类片子的运动（大面积近黑、元素是细线和小字，单帧变化只占画面千分之几）：脚本可能报"运动时间占比 1–2%、最长静止 30 s 以上"，看联络表却是字在一直出。遇到下面任一情况，改用分带量：底色暗像素（亮度 < 0.08）≥ 90%；主体是线和字；没有旁白、屏下字幕在当旁白。

1. **分带**：至少三条——屏下字幕带、屏中主文字带、全画面（避开平台水印区）。用 ffmpeg 10–30 fps 按带裁出，算逐帧**墨量**（亮像素占比）与相邻帧差。
2. **字幕起止**：字幕带墨量按"有字 / 无字"分段（阈值取无字段 p99 之上；容 2 帧断口）；每段的半高起止 = 这一句的出现 / 消失时刻。由此得字幕句数、在屏时长、句间空、读速（汉字数 ÷ 在屏时长）。
3. **过程事件的旁证**：打字、滚动、计数这类过程常有密集的过程音——用音频起音（谱通量超过中位 + 8×MAD）找成簇的起音，和联络表对照，补帧差漏掉的事件。
4. **报告写明**：用了分带、各带的裁切范围与阈值、起音阈值；整帧读数照常报，但标"本片不可信，以分带为准"。

## 7c. 构图不动的整屏亮度脉冲 ≠ 硬切

整屏帧差 ≥ 0.30 或 0.10–0.30 的单帧跳变，除了"切"和"重构图"（第 5 节），还有第三种：**构图不动，整屏亮度一次脉冲（变亮又落回），落回时某处状态已变**（答案亮起、天气变了）。核对：跳变点前后各 0.5 s 用 ≥ 8 fps 抽帧，看背景元素位置是否逐帧不变、整体亮度是否先升后回。是脉冲就记"光脉冲换态"，不算剪辑，也不算换舞台。

## 8. 这些数字描述的是原片

量出来的是**原片读数**，进风格 skill 的 style-dna Part A；产线要不要照搬、怎么翻译由风格 skill 决定。例（仅示格式）：原片滑动中位 0.5–0.8 s、组入场错开 0.2–0.4 s、偶有慢推镜，而 H3 时间码产线写成镜头锁死 + 四分之一秒内完成的单次变化（技能 `h3-storyboard-writing`）。不要把原片时长直接写进提示词。

**节奏读数有两把尺，不能互填。** 本协议（`analyze_reference.py`）的事件、静止、运动占比用 ffmpeg scene_score：它是为找硬切设计的，匀速、带缓入缓出的平滑运动帧差变化小，几乎读成 0。产线 `h3_timecode` 节奏预检、`h3_align` 成片读数和风格块的 `target_*` 键用的是像素口径（h3-pi-agent `bridge/h3_rhythm.py`：每帧变化像素占比，和 `h3_align` 同算法），同一期 scene 口径 2%、像素口径 17%（`h3_rhythm.py` 头注，10-01）。所以：风格 skill 里的节奏读数写明口径；给一个风格定 `target_events_per_min` / `target_motion_share` / `max_still_p50_s`，要用像素口径量原片——现在 `h3_rhythm.py` 只有函数、没有命令行入口，要量先跟用户说，别把 scene 口径的数填进去。墨量、色面两项两边同算法，可以直接填 `target_ink` / `target_color_area`。
