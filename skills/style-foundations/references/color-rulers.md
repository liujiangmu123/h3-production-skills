# 配色尺子 — Color Rulers（行业通识；分析时逐条问）

每条 = 定义 → 分析判问 → 四态形态。读数记进被分析风格自己的文件。**具体色值（hex）永远是读数不是尺子**——尺子只问"怎么决定颜色"。

## 一、色轮关系（配色骨架）

- **互补**（对冲最强张力）／**类似**（和谐同族）／**三角**／**分裂互补**／**单色系+点缀**。
- 判问：全片色彩关系属于哪种骨架？骨架跨期稳定吗（＝风格）还是随题材换（＝槽位）？

## 二、冷暖与光源物理

- 冷暖不是滤镜偏好，通识上**来自光源**：暖=火/夕阳/白炽灯/烛；冷=天光/月/阴天/荧光。
- 判问：该风格的冷暖从哪来？有没有冷暖**交替的节奏规律**（几镜一换）？冷暖同帧时谁是底谁是点？
- **光源一致性（single lamp check）**：全帧从最暗到最亮是否偏向同一色温方向？混光是失误还是修辞？

## 三、饱和度与明度策略

- 谱系：全高饱和（少儿/游戏感）→ 统一低饱和做旧（岁月感）→ **无彩底+单点高饱和**（注意力武器）→ 高级灰莫兰迪（含蓄）。
- 判问：饱和度的"允许区间"是多少？高饱和是否被限量配给？给了谁（语义上最重要的东西？仪式感器物？）？
- 明度：灰阶层数（2-3 层=图表感，10+层=世界感）；黑是否纯黑、白是否纯白（一步之差=有光 vs 死平）。

## 四、色彩预算与数量

- 通识起点 60-30-10（主-辅-点缀）；强风格往往**改造成自己的极端比例**。
- 判问：实测彩色像素占比的常态带？同屏色相数上限？首个彩色出现在第几秒（色彩是否被当作叙事事件延迟发放）？
- 量化必答：色彩占比带、色相数上限、首彩延迟——这三个数是配色风格的可验收骨架。

## 五、语义色与文化色

- 跨文化较稳的 UI 语义：红=错误/警告/停，绿=正确/通过/行；蓝红对=对比双方（冷暖对立）。
- 文化仪式色：华夏朱红/鎏金、宗教金蓝、品牌色。判问：作者用语义色吗？语义色与美学色冲突时谁让路？
- **颜色来源三问**（通用推导起点）：题材世界自带的标志色？材料物性色？还是纯注意力工程色？——作者的取色公式是哪种，比他取了什么色更重要。
