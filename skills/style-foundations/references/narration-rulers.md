# 旁白与文案尺子 — Narration & Copy Rulers（行业通识；分析时逐条问）

每条 = 定义 → 分析判问 → 常见做法。读数、取舍、逐字样例记进被分析风格自己的 `narration.md`，这里只放通识。量的口径（字/秒、停顿、句数）见 `measurement-protocol.md` 第 6 节「旁白」行；素材是 `analyze_reference.py` 输出的 `transcript.json`（ASR 分句 + 时码）+ 人工逐字校对。

**没有旁白的风格**（诗词朗诵、纯音乐、字幕文案）也过这张尺子：把"旁白"换成它实际用的语言层（朗诵的诗句、屏上字、歌词、音乐的段落结构），不适用的维度标"不适用"。

## 一、声音节奏（可量）

| 维度 | 量什么 | 判问 |
| --- | --- | --- |
| 语速 | 出声字/秒、全片字/秒 | 快讲（≥5）/ 常速（3.5–5）/ 慢讲（<3.5）？全片稳定还是分段变速？ |
| 句长 | 字/句 p25 / p50 / p75；最长句 | 短句链、长短交替、还是长句铺陈？长句放在哪（开头 / 高潮 / 收尾）？ |
| 停顿 | 句间停顿 p50 / p90；≥1 s 停顿次数与位置 | 旁白不停（气口 <1 s）还是留大白？大停顿落在哪一句前后？ |
| 首句 | 首句开口时刻 | 0.3 s 就开口，还是先给画面 / 音乐？ |
| 覆盖率 | 有声时长 ÷ 全片 | 旁白铺满，还是只在关键处出现？ |
| 句群 | 几句成一组、组间怎么换气 | 两句一对、三句一组、还是自由流？ |

## 二、句法

- **句型**：陈述 / 设问 / 反问 / 感叹 / 祈使的占比；问号几个、在哪。判问：作者是在陈述、提问、还是招呼观众？
- **句式**：对举（"一个是……一个是……"）、排比、短句链、"X，就是 Y"定义句、条件句。判问：最常用的 2–3 个句式是什么？每个抄 3 句原文。
- **人称**：我 / 我们 / 你 / 无人称。判问：讲述者站在哪（老师、同伴、旁观的说书人）？
- **虚词与口头禅**：其实、那么、你知道吗、没错、划重点、今天我们来聊。判问：用不用？不用就是"拒绝"，记下来。

## 三、修辞

| 手法 | 判问 |
| --- | --- |
| 比喻 / 类比 | 用不用？喻体从哪来（日常物、身体、自然、机器）？一期几次？ |
| 反差 / 翻转 | 有没有"你以为 A，其实 B"？放在开头还是中段？ |
| 数字与实物 | 讲抽象概念时落不落到具体数字、具体东西上？ |
| 重复 / 回扣 | 开头的句子或意象结尾有没有回来？ |
| 感官词 | 写看到的、听到的、摸到的，还是只写概念？ |
| 金句 | 有没有一句可以单独截图转发的话？句式是什么？放哪？ |

## 四、结构（旁白怎么推进一期）

- **开场**：第一句是什么类型。常见：实物直入、认知翻转、悬念、数字反差、直指痛点、新鲜类比、自问自答、感官验证、冷开场"这是 X"。判问：作者用哪几种？从不用哪种？
- **推进**：总分 / 递进 / 转折 / 并列 / 时间顺序；段与段之间的转场句长什么样（抄原文）。
- **信息顺序**：术语什么时候出现（先演示后命名，还是先给名字）；一句承载几个信息点。
- **收尾**：金句 / 回扣开头 / 落到观众身上 / 行动号召 / 留白；有没有固定结尾口播（抄原文）。
- **长度结构**：全片几段、各段句数，高潮句在全片百分之几的位置。

## 五、口吻与人设

- 讲述者像谁：老师、朋友、说书人、诗人、主持人、纪录片解说。
- 表演性：情绪词、夸张、语气词多不多；是"讲"还是"演"。
- 可信度装置：出处、年份、数字、"一说"。
- 判问：内容不变、只换掉口吻，作者感觉还在吗（作者本人还会这样讲吗）？还在 → 口吻是作者默认；没了 → 口吻是本质。

## 六、声画关系（旁白和画面谁领谁）

| 关系 | 识别 |
| --- | --- |
| 旁白领画面 | 先说，画面随后出现（偏移中位为正） |
| 画面领旁白 | 画面先动，旁白随后命名（偏移中位为负；"演示先于命名"） |
| 声画反相 | 旁白不停时画面常停，画面动时旁白换气 |
| 同步 | 说到哪画到哪 |
| 互补 / 冗余 | 旁白说画面没画的（互补），还是复述画面（冗余）？ |

判问：旁白提到一个东西，画面在它说出前、说出时、还是说完后出现？这是可量的（`measurement-protocol.md` 声画咬合行）。

## 七、行业常见做法（当尺子，不是规范）

开头 3 秒给钩子；一句一个信息点；口语化、短句；有反差或悬念；中段有"原来如此"；结尾金句或行动号召；知识片每 20–30 秒一个小高潮。逐条标作者的态度（采纳 / 改造 / 拒绝 / 不适用）。拒绝的一条写清用什么补偿（例：拒绝开头提问 → 用一句冷陈述 + 画面上的一个异物做钩子）。

## 分析时必交

1. 上面一至六节的读数表 + 第七节行业做法四态表（每条带片 ID + 时码）。
2. **逐字样例 ≥15 句**，覆盖开场、转场、高潮、收尾、固定口播，每句标时码和它示范的手法。
3. 作者**从不说的话**清单（逐条可判定，例："不说'大家好'"）。
4. 旁白层的三层归类：哪些是本质、哪些是作者默认、哪些每期自由（方法见 SKILL.md 三层分离法）。
